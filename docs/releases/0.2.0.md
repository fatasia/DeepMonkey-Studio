# DeepMonkey Studio 0.2.0

本次更新面向需要编辑工程场景、组织业务本体并交付离线应用的用户。

## 更新

- 处理流程支持自由拖拽、端口连线、改接、撤销和节点输入/输出调试；保留已有流程位置与连接。
- 本体图谱显示完整关系，支持对象拖线后填写关系、字段映射、基数和证据；发布版本通过新草稿编辑。
- 修复 Deep 作者贴图方向、实时 UV 更新、曝光/雾参数与编辑器辅助图形；补齐生产 cluster-LOD 和 RT 二反弹路径。
- 滑条连续预览、结束时一次提交，项目轮询避免相同快照重复刷新整页。
- 发布资源冻结字节和校验和；提供离线 SDK、客户端与应用容器交付，并更新两个介绍视频。

## 安装与使用

发布附件的 `SHA256SUMS.txt` 对应本次全部下载。SDK 见 [安装说明](../sdk-release.md)，Docker 见 [应用部署](../docker-application.md)，在线浏览范围见 [浏览说明](../guides/online-browser.md)。

流程连线、节点调试和本体关系保存见 [数据中心编辑指南](../guides/data-center-editing.md)。

编辑器零配置默认 Three/WebGL，保留显式 Deep WebGPU 和 Deep WASM 选择。本次客户端面向 Windows x64，不提供 Android 包。

产品版本统一为 0.2.0；场景协议与 Unity bridge 的独立版本保持原合同。备份已有工程后升级，安装/启动覆盖范围按本次产物验证记录。

## 发布验证记录

Deep WebGPU 与 WASM 的滚轮、触控缩放方向现在与 Three 一致。场景编译合并重复请求，后台预备按场景版本复用；停放的引擎暂停渲染，并释放空闲渲染目标和重复传输数据。

SMT 在 RTX 4060 Laptop 上实测：首次准备 WebGPU 约 3.5 秒、WASM 约 5.8–6.3 秒；刷新后两者约 4.4–4.7 秒，准备后的切换为毫秒级。连续切换 30 次、两引擎各拖动 30 秒，无页面错误和超过 50 ms 的主线程任务。WASM 线性内存由约 220 MiB 降至 124 MiB。冷启动与特殊材质画质仍随硬件、场景变化。

新增资产持久缓存、按材质功能编译管线、按需创建后处理和 GPU mipmaps。修复桌面冻结场景纹理请求、统一滚轮方向，减少重复纹理解码和复制。SMT 运行包由约 160 MB JSON 改为约 4.9 MB 二进制传输；GPU 解压后的纹理占用单独统计。

附件包含源码、Windows 编辑器安装包、Windows SMT 冻结场景示例、离线 Docker 镜像与启动配置、SDK、在线前端及视频；下载后按 `SHA256SUMS.txt` 核对。GitHub Pages 打开即可编辑 SMT，内置 275 项模型、HDRI 和 PBR 素材及 30 行示例数据；编辑和素材导入保存在当前浏览器。工业转换、服务端数据流程和 Agent 使用 Windows 或 Docker 完整部署。

Docker 支持单容器本地存储启动，也提供带 PostgreSQL、MinIO 的 Compose 启动包。完整素材库超过 Pages 容量，另见 [素材库 Release](https://github.com/fatasia/DeepMonkey-Studio/releases/tag/asset-library-v1)。

Native MegaLights 当前 Vulkan 路径已有实机证据；当前 DX12 适配器缺少所需 ray-query 特性时使用簇光回退。实验路径和特殊材质一致性按具体平台记录。
