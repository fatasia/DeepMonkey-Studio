# 看板作者与匿名运行字号一致性验收

## 已完成

本批只修复工作台壳层覆盖作品字号和控件尺寸的问题，不调整画布比例，不重做行业模板，不改变账户、存储或业务数据。

### 根因与修补

- 真实 Chrome 的 computedStyle 与祖先变换证明：作者、匿名视图都只有一层画布缩放，1440px 为 `0.75`，980px 为 `0.510417`；不存在二次缩放。
- 作者页面的 `.app-workspace-frame` 命中 `accessibilityReadability.css` 的 `font-size: 12px !important`，把 KPI 原定 27px、标题原定 16px 同时压成 12px。匿名页面无此祖先，因此保留原字号。
- 三条工作台规则（字体、控件最小尺寸、表单标签高度）统一排除 `.dashboard-artboard *`。设计画布与运行画布由作品自身样式控制，壳层仍保留可读性与点击目标下限。
- 聚焦测试新增 `dashboardTypographyBoundary.test.ts`；实际浏览器新增 `gate-dashboard-runtime-typography.mjs`，同时记录字体、匹配样式规则、元素矩形与祖先变换。
