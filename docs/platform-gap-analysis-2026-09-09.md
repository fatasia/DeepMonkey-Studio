# 主流平台差距调研报告（2026-09-09）

> 对标基线：山海鲸可视化、优锘 ThingJS、帆软 FVS（FineVis）、Unity、西门子 PS/PD/Plant。
> 信息源：内部既有实测对标研究（`docs/editor-interaction-benchmark-2026-09-04.md`，基于三家官方文档抓取）+ 本轮公开信息补证 + 本仓库台账实测状态。不宣称做过全部竞品的实机评测。

## 一、外部平台现状速览

| 平台 | 定位 | 关键能力 |
|---|---|---|
| 山海鲸 | 免费零代码数字孪生大屏 | 自研 Web 引擎 Cetus3D（宣称对标游戏引擎画质）、BS/CS 双模切换、海量行业模板、零代码拖拽 + 二次开发 |
| ThingJS（优锘） | IoT 3D 可视化开发平台 | ThingJS-X 零代码平台 + 开发者 JS API 生态、园区/楼宇/设备四级钻取动线成熟、插件/生态市场 |
| 帆软 FVS | 零代码大屏（FineReport 插件） | 官方 Demo 库 **200+ 模板、10+ 行业**在线预览即下即用、组件可自定义、报表导出、数据流定时刷新 |
| Unity | 游戏/实时 3D 引擎基准 | 渲染管线（URP/HDRP）、PBR、后处理栈、资产商店生态 |
| 西门子 PS/PD/Plant | 工业工艺仿真 | 工位级碰撞/节拍/路径仿真、PPR/BOP 结构化流程、设备状态语义与证据纪律 |

## 二、我们已达到或超出主流水位的能力（实测有证据）

- **四编辑器一体**：2D/3D/脚本/拓扑共享项目场景上下文——山海鲸/帆软以大屏为主，无同级脚本与拓扑编辑器；ThingJS 需要写代码。
- **发布四通道**：WebGL / WebGPU（可回退）/ 云渲染 / Windows 只读客户端——山海鲸 BS/CS 双模类似，但我们的云渲染有 WebRTC 媒体证据门禁与不可变发布版本合同。
- **数据填报写回**：REST/PG 参数化写回 + 409 保稿 + 未知结果不重放——帆软系以只读展示为主，填报回写是收费版弱项。
- **仿真闭环**：Plant Lite（离散事件/置信区间）、PS Lite（碰撞/节拍/信号）、PD Lite（PPR/BOP）+ Study 证据链——这是与国内大屏平台**最大的差异点**，山海鲸/ThingJS/帆软均无同级能力。
- **AI 融合**：统一工作台、AskData、脚本 AI、当前页草案应用——主流平台仅有或没有简单 AI 问答。
- **工程纪律**：2199 源文件 ≤800 行、全链测试 2000+ 项、离线部署（`pnpm studio`）、PostgreSQL+MinIO 生产拓扑——工程可维护性高于多数零代码平台（它们不开源源码）。
- **素材库治理**：来源/许可/哈希/审核记录全链留痕——主流平台的模板库无同级许可治理。

## 三、差距矩阵（按平台逐家，标注差距与补齐路径）

| # | 差距 | 现状 | 差距量级 | 补齐路径 |
|---|---|---|---|---|
| 1 | **行业模板量**：山海鲸"海量模板"开箱即用 | 看板模板 120（12 行业×10）+ 行业深度包 3 包 15 页 | 大（数量级） | S3-C 行业包扩容（本轮进行中，3→10 包），模板目录扩到 300+ |
| 2 | **场景模板/行业 Demo 场景**：一键开箱的完整 3D 场景 Demo | 有预置预制体与场景样例，无"开箱即用的完整行业 3D 场景" | 中大 | 把行业包与 3D 场景打包为一键 Demo 场景库 |
