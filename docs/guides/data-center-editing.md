# 编辑数据流程与本体关系

数据中心把接入、处理、接口发布和语义模型放在同一个工程里。0.2.0 的处理流程与本体图谱都支持拖拽、缩放和端口连线。

## 处理逻辑

进入「处理逻辑」，选择已有流程或新建流程。

1. 选中节点，在右侧配置数据集、过滤条件或输出字段。处理模块可插入当前节点之后；多路数据用「合并」节点。
2. 拖动节点调整位置；从输出端口拉到输入端口创建连接。选中连线后拖动端点可以改接，点击「删除连线」或按 Delete/Backspace 删除。
3. 用顶部撤销/重做恢复编辑；「整理布局」按当前连接重新排列节点。位置和连接先留在草稿，点击「保存」后持久保存。
4. 点击「运行」执行整条流程，或选中节点点击「运行到此」。下方切换「输入」「输出」，查看行数、字段和样例；失败节点显示错误。

画布拒绝自连、重复连接、环路、向数据源输入，以及从输出节点继续连线。普通处理节点只接收一路输入，多输入接「合并」节点。未接完的草稿可以继续编辑；保存和运行时还会检查完整流程与配置。

节点调试显示样例行，旁边的总行数是该节点的实际输入/输出量。改动配置后重新运行才能得到新结果。

## 本体图谱

进入「语义模型」，选择本体包。左侧按对象、数据、行动和事件定位资产；搜索、类型筛选和1–3跳展开用于查看相关关系。点击节点或边，在右侧检查属性、来源、版本与证据。

图谱中的对象拖动用于整理当前阅读布局；它不修改业务关系，也不会写回本体契约。缩放、平移和「重置视图」同样属于阅读操作。

编辑业务关系：

1. 点击「编辑关系」，从对象端口拖到另一个对象。数据源、事件和行动绑定在对应资产中配置。
2. 在关系配置中填写标识、名称、方向、基数、两端字段映射、建立理由与证据。拖动已有关系端点可改接；双击关系或点击「编辑关系」也能打开配置。
3. 草稿包点击「保存关系」。已发布包点击「保存到新草稿」，原发布版本保留；取消或关闭配置不会创建关系。

保存前会重新检查包的版本。若提示本体已变更，关闭配置、重新查询，再编辑。关系保存到草稿后，仍须按本体发布流程完成确认和发布。

窄屏默认使用列表阅读；进入关系编辑后提供可拖线的画布。三维离线查看工具见 [在线浏览说明](online-browser.md)，本体与处理逻辑编辑使用完整工作台。
