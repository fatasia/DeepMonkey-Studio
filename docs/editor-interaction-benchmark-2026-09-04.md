# 编辑器交互对标研究与采用设计（2026-09-04）

状态：研究结论 + 采用设计 v1（GLM-5.3 依据官方文档研究与既有路线图整理）
触发：用户反馈"2D/3D/脚本编辑器、素材模板、数据中台的交互逻辑还是不好，学习 ThingJS、山海鲸、帆软"。

## 1. 对标事实（来源：官方文档，2026-09-04 抓取）

### 帆软 FVS（大屏编辑器）

组件操作：
- 添加双模式：**单击组件类型 = 添加到画布正中央；拖拽 = 落点放置**。
- 快捷键：Ctrl+C/V；**alt+左键拖拽 = 快捷复制**；Shift 点选或左键框选多选；图层列表 Ctrl 点选多选/减选、Shift 连选。
- 遮挡选择：**悬浮目标上方右键 → 图层列表（自上而下）快速选中被遮挡组件**；**Ctrl+左键穿透组合选中子组件**。
- 层级：置顶/置底/上移/下移；图层拖拽或右键调整；图层右键支持**批量复制/粘贴/隐藏/锁定/调层**。
- 锁定=画布完全不可操作直至解锁；隐藏=编辑态不可见不可选但图层列表可选、配置仍可改。
- 组合：多选 → 右侧配置栏"组合"或右键；组合可整体调层/动画/尺寸位置，删除组合连带删除组内组件。
- **跨模板粘贴组件可携带数据集；目标有重名数据集时自动匹配不覆盖**。

交互配置（事件-动作模型）：
- 入口：选中组件 → 「交互」页签 → 添加事件（鼠标点击等）→ 挂动作。
- 动作库：组件联动（传参）、分页跳转、网页链接、弹出框、显示/隐藏、JavaScript、三维漫游/模型动画/自定义视角/环境效果。
- 事件管理：悬浮事件名可重命名/复制/删除；多动作时可选触发方式。

### 帆软 FineBI（联动模型）

- **默认联动**：多个组件用同一数据表，或表在「模型视图」中建立关联 → 系统默认联动；总开关"开启默认联动"可一键关闭，默认联动也可手动改。
- 自定义联动：勾选目标组件；跨表时在「自定义」界面添加**依赖字段**（联动的依据）；**两侧字段类型不一致标红、无法联动**；依赖字段不可重复使用。
- 方向规则：同表或 1:1 → 双向；1:N → 单向。
- 条件语义：**同一联动组件只能传一个过滤条件（后点替换先点）；多个不同组件的条件为"且"叠加**。
- 范围：仅限同一仪表板内部；明细表/文本只能被联动不能触发；无指标字段的图表点击不触发。

### 山海鲸（低门槛路径与数据绑定）

- 首页即项目缩略图（保存自动更新）；左侧资源中心独立入口；左下角图文/视频教程与客服；**删除进回收站二次确认**。
- 新建两起点：空白大屏 / 大屏模板；文档按**七步入门**组织（新建→模板→连数据→绑数据→改样式→预览→部署）。
- 数据绑定（拖拽槽位模型）：选中组件 → 右侧切到数据页 → **字段右侧 X 删除"组件自有示例数据"字段 → 从项目公共数据列表把字段拖入字段槽**。
- 数据两级模型：**项目公共数据**（数据源加入项目，全子看板可用）vs **组件自有数据**（内置示例，新组件默认用）。
- 数据源广度：文件/API/WebSocket/Webhook/20+ 数据库/物联中台。

### ThingJS / Unity（路线图 2026-09-02 已研究，沿用）

- ThingJS：脚本与场景上下文绑定；代码、预览、运行诊断同一工作区；脚本窗口分屏/悬浮/隐藏；错误回具体行列。
- Unity：Hierarchy 只管层级与选择、Inspector 只管当前上下文；库资源可拖入层级或视口；多选/拖拽/重命名/快捷键/右键指向同一命令；多选出现批量属性。

## 2. 采用设计：五个面的差距与目标交互

> 原则：复制的是**交互模型与心智**，不是像素皮肤（roadmap §3 纪律）。以下按面列出"现状 → 目标"，形成 EX 批次。

### EX-001 2D 画布交互对齐（对标 FVS 组件操作）

现状：有拖放/吸附/多选/编组/右键，但选择模型、快捷键、图层批量、锁定隐藏语义与 FVS 存在差距（需夜间先盘点现状清单再逐项补齐）。

目标交互：
1. 单击资源 = 画布居中添加；拖拽 = 落点放置（双模式）。
2. alt+拖拽快捷复制；Ctrl+C/V（含跨页面粘贴，携带数据绑定，重名数据集自动匹配）；方向键微调位置。
3. 悬浮右键 → 图层列表选被遮挡组件；Ctrl+点击穿透组合选子组件。
4. 图层列表右键批量：复制/粘贴/隐藏/锁定/调层；多选支持 Ctrl 减选。
5. 锁定 = 画布不可操作（仅图层列表可解锁）；隐藏 = 不可见不可选、配置可改。
6. 组合整体可调层/动画/变换，删除组合连带成员（需确认已有语义，缺则补）。

### EX-002 2D 字段拖拽绑定 + 数据面板（对标山海鲸/FineReport 槽位模型）

现状：绑定靠 Inspector 里下拉选数据产品 + 下拉选字段（DashboardInspectorData.tsx 760 行）。

目标交互：
1. 选中组件右侧出现「数据」页签：字段槽（维度/指标/系列槽位按组件类型呈现）。
2. 右下/右侧常驻**数据面板**：项目公共数据（数据中心数据产品+语义模型）列表，字段可拖拽。
3. 拖字段入槽 = 绑定；槽内字段右侧 X = 解绑；类型不匹配槽位标红拒绝。
4. 未绑定时组件用**内置示例数据**渲染（山海鲸两级模型），绑定后替换——新组件即拖即有所见。
5. 槽位与现有 `analysis`（dimensionField/measureField/seriesField）配置双向同步，不是平行第二套。

### EX-003 联动与钻取交互模型（对标 FVS 事件-动作 + FineBI 默认联动）

现状：linkageParameterKey 写共享参数 + parentFilterKey 级联 + drillFields 手填（组件级原语齐但配置分散、无统一入口）。

目标交互：
1. 选中组件 → 「交互」页签 → 事件（点击/值变化）→ 动作（联动目标多选、跳转页面/URL、显示/隐藏、脚本、3D 相机定位）。
2. 同数据源（S1 后同语义模型）组件**默认联动**，页面级总开关 + 单组件可退。
3. 跨源联动走依赖字段匹配：两侧类型一致才可连，不一致标红（FineBI 规则）。
4. 条件语义对齐 FineBI：同组件后点替换先点；多组件条件"且"叠加；明细/文本只能被联动。
5. 钻取层级改为从**维度层级定义**选择（依赖 S1-001 维度 hierarchy），不再手填字符串；面包屑回退保留。

### EX-004 3D 编辑器交互深化（对标 Unity/ThingJS）

1. 场景树完整键盘操作（上下/展开/选择/多选）；treeitem 语义补全（roadmap P0 遗留）。
2. 多选出现批量属性面板（位置/显隐/材质/动画开关），不再显示单选空态。
3. 资源面板条目可**拖入场景树或视口**，插入后自动聚焦 + 检查器自动展开关键参数（Unity 规律）。
4. 相机视角书签：保存/命名/一键恢复/设为初始视角。
5. 检查器严格"当前上下文"：空选=场景，单选=对象，多选=批量，不复用 2D 面板样式。

### EX-005 脚本编辑器辅助升级（对标 ThingJS）

1. API 提示面板：`studio.*` 常用命令分组速查，点击插入光标处。
2. 样例库：可运行片段一键插入并定位错误（与 S4 SDK 文档样例同源）。
3. 诊断常驻化：运行日志/错误/依赖三合一底部面板，可折叠，错误点击回行列（已有）不丢。
4. "挂载到"目标选择器：按场景/页面分组 + 搜索 + 同名上下文区分（roadmap P1 遗留）。

### EX-006 素材与模板体验（对标山海鲸资源中心）

1. 双入口一致：独立资源中心页 + 编辑器内资源面板共享同一目录/搜索/收藏/最近。
2. 新建场景两起点：空白 / 模板预览选择；模板卡真实缩略图 + 行业筛选。
3. 拖入即用：插入后自动聚焦、关键参数自动展开、可撤销（roadmap 批次 4）。
4. 模板七步式首run路径：新建→选模板→连数据→绑数据→改样式→预览→发布，每步有下一步入口（内嵌引导，不常驻）。

### EX-007 数据中台向导化（对标山海鲸连数据 + FineBI 字段结构）

1. 连接向导：类型 → 地址/凭据 → **测试** → Schema 预览 → 保存，一步到底不离开向导（roadmap 批次 5）。
2. 数据集字段结构常驻预览：字段/类型/示例值三列，漂移高亮。
3. 发布接口试调用与复制示例一步完成。
4. 术语与 2D 统一：数据产品、字段、联动在两处同名同义。
5. 删除数据资产进**回收站语义**（软删除 + 引用保护提示），与山海鲸容错一致——级联 409 保留但提示可追溯。

## 3. 排序与依赖

EX-001（纯交互，无依赖）→ EX-002（依赖数据面板设计）→ EX-003（依赖 EX-002 的槽位 + S1-001 维度层级）→ EX-004/005/006（独立，可插排）→ EX-007。
与 S 系关系：S1-001（今晚，纯合同）先行；**EX 系列插队到 S1-002 之前**——S1-002 语义模型编辑器与 S1-003 语义绑定直接按 EX-002/EX-003 的新交互实现，避免同一面板做两遍。S2/S6 依赖不变。

## 4. 验收与证据纪律

- 每个 EX 批次：白天出规格（现状盘点 → 逐项差异 → 文件计划）→ 夜间实现 → 真实浏览器截图（双主题）+ 键盘可走查 + 聚焦测试。
- 快捷键/选择模型类改动必须有交互测试（模拟按键序列断言结果），不能只测 DOM 存在。
- 所有交互文案进术语表；不复制竞品视觉皮肤；竞品名不进源码。
