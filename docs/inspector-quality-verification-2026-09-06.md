### 已证实的问题及修复

| 真实问题 | 核验与处理 |
|---|---|
| 浅色检查器仍有旧深色表单、灰色读数；暗色轴标和单位对比度不足 | 基线颜色 HEX/透明度读数浅色对比度 **1.53:1**，轴标/单位两主题约 **3.47–3.52:1**。上下文卡片、输入、外观分组、读数和空态统一到既有令牌。 |
| Esc 取消数字草稿可能在 blur 中反提交旧草稿 | 用同步取消 ref 跨过 React 更新与 blur 时序；浏览器验证取消、空字符串、负号、Infinity、超大指数和中文无效输入均恢复原值，Enter 有效值正常提交。 |
| 锁定数字与正常数字外观近似 | 保留真正的 disabled 状态，补 opacity 0.5 和 not-allowed；锁定图标与“已锁定”文本保留。 |
| 焦点写死金色，且数字输入出现内外两圈焦点 | 限检查器范围覆盖公共焦点色；数字框只保留外层 label 焦点，跟随运行时 `--accent`。默认金色与蓝紫色品牌均复核。 |

同族检查覆盖检查器空态、外观/材质/特效子面板、属性展示、位置/旋转/缩放、锁定与焦点；没有顺手修改顶栏、左目录或共享品牌体系。`inspectorContext.css` 已通过首行 CSS import 接入 `sceneInspectorControls.css`，无需重复增加 `editorStyles.ts` 接线。
