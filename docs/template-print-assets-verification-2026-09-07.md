## 已完成：本批实现

- 模板库：空搜索/空收藏有恢复入口；打开聚焦搜索框、Tab 循环、Esc 返回入口；弹窗阻断后台画布快捷键。双主题与 480/800 窄窗；单个搜索结果不拉伸成整行超宽卡片，长说明转悬浮提示。
- 模板缩略图：与插入节点共用布局工厂，显示全部九个区域及目标页面长宽比；去掉固定 86.4/97.2 等虚构指标。**这是结构预览，不是数据已绑定或渲染效果截图**。目录保持120项，不凑数。
- 打印：当前画布等比适配 A4 横/竖版、8mm 边距；不沿用窗口缩放；不输出编辑/发布工具；退出打印恢复原尺寸。直接使用现有运行 DOM，未复制画布或重跑脚本。
- 优化器取景：真实输送带出现裁切，根因为原公式按世界轴长宽估算，未考虑斜视投影；复用场景编辑器八角点算法，原 GLB、材质、尺寸不改。

设计依据沿用 [Unity Inspector 的上下文编辑](https://docs.unity3d.com/Manual/UsingTheInspector.html) 和既有帆软式设计画布/等比适配原则，界面沿用 base.css 令牌；这不代表完整 FineReport 打印产品能力。
