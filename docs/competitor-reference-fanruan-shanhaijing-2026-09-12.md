## 2. FVD(fvd.fanruan.com)素材库结构

### 2.1 信息架构
- 顶部:Logo + 首页/反馈 + 全局搜索 + 消息 + 头像;登录横幅插画区。
- 三个一级分区(tab):**项目 / 素材 / 经验**——分别对应完整模板、组件素材、教程经验帖。
- 列表页统一模式:筛选条 + 卡片瀑布流。

### 2.2 筛选体系(直接可复刻的组织方式)
- 项目 tab 七维:终端 / 场景 / 行业 / 业务 / 色系 / 尺寸 / 风格,各维"不限"缺省;右侧 排序(最新)+ 价格。
- 素材 tab 五维:状态 / 行业 / 风格 / 类型 / 终端 + 排序(最新)+ 价格。
- 标签分类浏览(素材):catenum=1 后台、2 skills、3 风格、5 静态——按"用途族"聚合。

### 2.3 卡片结构
- 封面(纯图,约 16:9)+ 标题(下方,小号深色字)+ 元数据行(浏览数/收藏数 · 上传人 · 上传于 日期)。
- 首页 5 列网格;封面即全部视觉,**无叠加徽章/描边/装饰**——干净、封面质量决定一切。
- 排序默认"最新"。

### 2.4 详情页结构
- 大图轮播预览(多图)+ 标题 + "下载"主按钮。
- 基本信息:创建人、更新时间;素材简介:"适用于:XX看板、XX看板"句式。
- 素材标签行(可点击跳转同标签列表);全部评论 + 发表评论输入。

## 4. 帆软 FVS 官方视觉规范(帮助文档原文要点)

- **深色基底**(官方理由:视觉疲劳少、拼接屏色差小、省电);色系优先级:蓝→青→红黄绿。
- **行业色调映射**:IT/公安/水利=蓝;电网/能源/环保=青绿;零售电商=红黄;党建=红;酒店=香槟黄。
- **布局**:中心呈现主信息,周围对称分布次要信息。
- **图表块净化**:去自带标题、去单系列图例、去坐标轴线、去系列框线、去背景横线、去密集标签/工具栏。
- **文字**:浅色(纯白/浅灰 #eaeaea 级),字号随画布规格缩放。
- 资源中心:模板/组件/图片/视频四类,在线+本地双来源。

## 5. 山海鲸(shanhaibi.com)要点
