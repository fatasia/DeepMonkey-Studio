# 场景等待热力与运输轨迹 · 2026-09-08

## 已完成：实现与聚焦检查

在已有单车 DES、场景实体保存、统一时间线、Study 复现基础上增量实现空间显示，不另建仿真算法、播放器或结果存储。

- 时间线提供“运输轨迹”“等待热力”两个独立开关，默认关闭。等待计数为**当前时刻的已记录等待物料数，单位件**，不是事件次数或时间累计占用，也不冒充未记录的完整队列。
- 等待热力聚合缓冲/工位/搬运节点的等待状态，不含外部源/完成汇；基于全部已记录物料，不被18个可见运动点上限截断。原轨迹截断提示继续保留，未补造被截断后的事件。
- 圆盘只落在 Study 原输入保存的场景锚点；无锚点的等待样本数量在时间线显示，不猜位置。透明度与半径表示数量，非容量百分比/利用率/认证拥堵指标。
- 运输轨迹只根据既有已确认起止时刻/实际后继节点画当前位置之前的线段；不猜第一条出边，不冒充道路交通或机器人轨迹规划。原 DES 连续运动插值不变。
- 时间线驱动暂停/倍速/前后定位；空间层不累计绘制帧数。覆盖层沿 helper 隔离约定，不进场景对象/模型导出，关闭释放几何和材质。原模型与实体不修改。
- 颜色读取 base.css 的 warning/accent/success；实时帧直通原覆盖层，仅等待计数变化才更新数量说明，不另加逐帧 React 状态。

根因不是“缺少仿真入口”：既有覆盖层仅支持18个事件点，缺节点聚合、空间图层与图层显示控制。新增代码独立在 `ScenePlantPlayback` 与 `scenePlantSpatialLayers`，时间线壳层仅替换仿真分支。

聚焦测试：5 文件20项通过（ScenePlantPlayback、plantLitePlaybackModel、scenePlantPlaybackOverlay、scenePlantSpatialLayers、scenePlantModel）；包含25个物料超过可见点上限、真实运输插值/分流/截断、反向定位、缺空间锚点、层开关清理、固定缓冲、释放与单一时钟。新空间图层控件通过 locale/tr 接入中英文，英文测试只覆盖新模块，不代表旧播放器全部本地化。Web typecheck 退出0，主线程 r47 根构建及全量测试通过；新增英文改动等 r48。
