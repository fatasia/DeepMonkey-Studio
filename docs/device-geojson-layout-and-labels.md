# 设备 GeoJSON 布局与模型标签

## 产品定位

该能力用于在没有精细设备模型、或只有设备台账与平面图时，快速建立可运行的工业数字孪生资产。每台设备先以轻量方盒表达，并使用稳定设备 ID 连接标签、实时数据、告警、维护记录和后续正式模型。

它不是 CAD/BIM 建模器，也不尝试从任意图纸自动识别所有设备。正式模型到位后，方盒可被替换，设备 ID 和业务关系保持不变。

## 当前工作流

1. 在三维编辑器左侧点击“导入”，选择“批量设备布局”。
2. 选择规则阵列，或导入 CSV、TSV、JSON、GeoJSON。
3. 使用比例与 X/Y/Z 偏移对齐已经导入的 DXF 或平面图。
4. 预览设备数量、坐标和尺寸；错误行会被阻断并显示原因。
5. 可导出标准 FeatureCollection，也可直接创建方盒与关联标签。
6. 保存项目后，方盒、标签及其稳定关联随场景恢复。

设备布局工具按需加载，约 14 KiB minified，不进入首屏主包。单次最多处理 5,000 台设备，避免错误数据冻结编辑器。

## 输入约定

表格会自动识别中英文字段：

| 含义 | 常用字段 |
| --- | --- |
| 设备 ID | `equipmentId`、`deviceId`、`设备编号`、`编号` |
| 名称/类别 | `name`、`设备名称`、`category`、`设备类型` |
| 场景坐标 | `x/y/z`、`坐标X/坐标Y/坐标Z`、`高程` |
| 方盒尺寸 | `width/height/depth`、`宽度/高度/深度` |
| 方向/颜色 | `rotationY`（角度）、`color` |

GeoJSON Point 的坐标顺序为 `[X,Z,Y]`：X/Z 是平面轴，Y 是场景向上轴。Polygon 会按第一外环的平面包围盒生成设备方盒，适合承接从 CAD 平面图提取的封闭设备轮廓。

## 模型标签现状

平台已有真实三维标签，不是二维图片覆盖：

- 点击模型表面或地面放置，带锚点和引线；
- 编辑名称、说明、颜色、大小、位置、显隐和锁定；
- 从对象目录定位标签或聚焦对应场景位置；
- 标签保存到场景与发布版本；
- 数据绑定可通过 `annotationId` 动态更新文字；
- 批量设备标签通过 `modelId + anchorName(设备 ID)` 与方盒关联。

与帆软成熟标签能力相比，仍应补充：模板化多字段布局、条件颜色/图标、缩放级别与遮挡策略、密集标签自动避让、点击钻取和统一 tooltip。应优先做“模板 + 条件样式 + 避让”，而不是继续增加低价值标签种类。

## AI 与本体的最小接入

- AI 只生成设备布局草案；页面展示新增设备数量、坐标范围和错误，再由用户一键应用或取消。
- 本体只保存“设备—测点—指标—空间/产线—维护事件”五类关系。
- GeoJSON 的 `equipmentId` 是唯一业务主键，禁止用显示名称做关联。
- 纯问答与只读分析不需要确认；只有改变场景、脚本、绑定或发布状态时才显示简化变更确认。
