# URDF / ROS 与本批功能收口

状态：已完成限定集成验证；不是全项目最终验收、真机验证或认证仿真。

## 可直接使用

- 素材库、模型优化器、场景导入统一接受 URDF 或带依赖的 ZIP；多描述文件先选入口，取消不上传。保留原始 XML、依赖与哈希，不压成失去关节的 GLB。
- 优化页提供真实预览、关节调整、原包下载、实际画面截图、ZIP 无损压缩和另存素材；返回素材后可再次预览并进入场景。预览调整不污染素材，场景作者姿态可保存。
- 场景实例独立关节姿态；限位、mimic、固定关节和 rad/m 合同；保存、刷新、2D 场景节点、公开读取保留实例与素材身份。场景包按真实资源去重，不能以同名文件错误复用另一资产。
- 检查器填写 rosbridge 地址、选择 ROS 1/2 与主题即可订阅；支持主题发现、遥测跟随。作者姿态与实时遥测分离，断开/换对象/离页清理并复原。
- 控制须本会话显式启用，只发一次目标 JointTrajectory，默认无自动命令、重连或重放。显示“已发送，未确认”，不伪造设备回执。
- 同批脚本真实 DevTools 断点/调用栈/局部变量/单步、模型实例/引用保持替换、SDK 文档样例插入运行与金色品牌令牌均已验证，详见 EX-006、模型实例报告和 S4-001。

## 根因修复与同族检查

- 原包加载等待网格与LoadingManager完成；只在机器人根做Z-UP→Y-UP，姿态之后取包围盒。闭包资源校验、ZIP限额/CRC/哈希、路径/实体拒绝与轴归一化有聚焦测试。
- 机器人优化页原来层级高于入口选择框；统一新增 `--layer-workspace/--layer-modal/--layer-toast`，并修全局工具层遮挡页头。全局弹窗门禁确认旧Esc和busy语义不退化。
- WebSocket构造移至专用adapter，架构门禁只开放该适配器的WebSocket，不放开整个领域目录网络访问。
- 独立模型替换保留旧Object3D与mixer，候选失败恢复同一运行对象；结构、动画和机器人合同不兼容时拒绝，不删除原资源。
- Monaco真实null.left来自括号连线层，禁用该缺陷层，缩进线和括号着色保留。两轮清空/撤销/缩放验证，无控制台过滤掩盖。
