## 实现与边界

- `modelId` 保持稳定场景实例身份；`assetModelId` 可选，旧场景缺省回退 `modelId`，不改写旧文档。引用实例的脚本、选择、标签、仿真实体不改成资源 ID。
- 同素材可新增多个独立实例。替换保实例 ID、名称、变换、层状态、动画、业务引用、相机及其他楼层；移除仅删除场景实例，业务引用可保留断链状态以便撤销。资源删除在场景、发布历史、应用资产/场景/发布版本仍引用时返回 409。
- 同项目、ready、manifest 与资源一致等校验没有放松。匿名发布元数据及桌面归档按实际资源去重，不按实例 ID 误取资源。
- 网络、结构预检与迟到响应失败不改原对象。候选注册/状态应用失败会重新挂载同一原 Object3D、作者状态与旧 mixer，提交成功才释放原资源。正常删除仍立即释放。系统性恢复失败显式报回滚失败，不承诺任意 renderer 异常都原子。
- IFC/Fragments 不开放此替换路径。跨 LOD 容器拓扑替换拒绝，避免当前看似兼容而保存恢复后层引用失效；同结构 LOD 替换先加载完整 geometry。动画按 `name || uuid` 核对。
- 既有 `/assets/*` 二进制路由并无发布资源鉴权白名单；本轮仅修匿名发布元数据过滤，不把它描述为新增二进制权限。
