# 源材质恢复与贴图隔离（2026-09-21）

在现有 glTF 材质槽内补充“恢复源材质”和“恢复单项”操作，保留当前作用域及其它槽的覆盖。

## 复用与修复

- 复用已有 `originalMaterialTextures`，原空 URL 语义确为恢复原始纹理，并非删掉纹理。恢复保留源纹理的 UV、旋转和环绕采样状态。
- 发现真实缺陷：恢复贴图没有停用 UV 动画；仅打开 UV 动画又可能直接修改共享源纹理。现恢复操作同时停用动画；动画只操作实例纹理克隆，原纹理保持不变。
- glTF 加载时记录真实源材质参数及线性颜色，克隆实例保留来源。源颜色以 `sourceColor/sourceEmissive` 恢复意图保存，Web 直接恢复线性浮点数，Deep 发布使用源解码材质相同数值；没有通过 #RRGGBB 量化值冒充精确来源。
- 可恢复当前槽或全部具备来源的槽；逐项支持基础色、粗糙度、金属度、自发光颜色/强度、法线强度、双面。恢复值进入既有槽 overrides、历史捕获和快照。再次编辑颜色会撤销对应源恢复标记。
- 停用模型屏幕时先恢复原屏幕材质，再应用源参数，避免旧屏幕备份覆盖刚恢复的材质参数。
- Native 编译明确接受空贴图 URL/名称与已停用的动画/屏幕，并继续保持源贴图；新增已有法线贴图强度的正确消费。未适配的活跃贴图、屏幕、动画仍拒绝。

## 证据

2026-09-21 18:19：材质槽实际渲染消费、GLTF 稳定身份、发布、Inspector 共 25 项通过；精确线性色与恢复后继续编辑 2 项通过；合同校验 12 项通过；Web 类型检查通过。

关键检查：选槽恢复不改其它槽；恢复后重新应用旧编辑状态可以还原；JSON 保存/重载后的恢复保留；源 UV 与采样不变；动画克隆释放一次；线性非 8 位颜色准确保持，正式包与 Web 同值。

页面撤销/重做操作和正式 Native EXE 画面对拍仍在集中验收范围。这一切片未扩展非 glTF 材质槽身份，也未宣称高级 PBR 和全部属性面板完成。视觉沿用 Inspector 既有令牌和紧凑操作行，最终统一截图评分。
