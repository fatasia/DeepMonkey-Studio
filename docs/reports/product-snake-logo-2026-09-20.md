# 青绿蛇形 Logo 全局替换验收

本轮以用户最后上传的渐变折带 S 形蛇标为准，覆盖此前扁平第三款。最终资源由可编辑路径与渐变组成，无嵌入位图、可见字标或黑色底板；属于对参考图的矢量重绘，不是 PNG 嵌入 SVG。

## 交付范围

- Web 登录、管理中心、工作台、加载状态、品牌设置、页签，以及独立 Web/Three 客户端的默认资源均复用 `public/brand` 现有入口。
- Tauri 客户端、NSIS 安装/卸载器、WiX MSI 与 Native 构建共用新 ICO；提供 16/24/32/48/64/256 六尺寸。PNG 和 ICNS 也由同一 SVG 生成。
- Native 默认打包在校验原候选 EXE 后，对副本写入当前图标，再追加运行包；兼容缓存引擎，原 EXE 与冻结证据 SHA 不变。显式客户图标优先，客户名称及品牌设置不被覆盖。
- 登录图标固定为 64px 高，支持宽幅自定义 Logo 的最大宽度约束。产品名称、UI 强调色、已有发布记录均保持原配置。
