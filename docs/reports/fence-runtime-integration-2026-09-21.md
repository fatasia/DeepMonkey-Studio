# 围栏预制体运行接线（2026-09-21）

本切片补上已有 `fence.modular` 参数到 Web 场景外观的缺口，不新建预制体库。

## 现状与改动

- 既有定义已有高度、立柱间距、门宽、面板类型；缩略图曾单独绘制网片，正式运行却落入通用设备盒体。
- 新增共享 `parametricFenceGeometry.ts`，缩略图与正式运行调用同一个米制构建器。两个固定围栏跨间加可选中央门扇；网格、实板、玻璃、电子围栏使用实际几何及 PBR 材质。
- `setIndustrialPrefabState` 传完整状态；围栏只在规范化几何参数变化时重建，运行状态变化不触发重建。同 kind 修改高度等参数立即生效。
- 根对象 ID、锁标记、位置/旋转/作者缩放保持不变。新插入围栏使用单位缩放，避免旧薄盒占位比例再次压缩米制尺寸。几何底面按原 primitive 底面锚定；已有作者 transform 不迁移。
- 更换或移除外观释放旧几何和材质，共享材质仅释放一次，保留并恢复原作者材质。上传模型组保持原资产外观。

## 剩余边界

- 门宽已影响几何；打开/关闭门动作仍需接正式行为系统，不以此切片宣称动作支持。
- `compileSceneRenderPacket.ts` 与 `sceneSnapshotRenderPacket.ts` 仍严格拒绝 prefab，Native 发布尚未获得围栏能力。后续须把此几何编译为正式 Mesh/材质合同，并补发布保存、Native 画面和交互对拍，不能直接删除拒绝条件。
- 现有 primitive 代理机制的原隐藏根几何参与包围盒/拾取等公共行为，仍应在统一正式场景视觉验收中核对；本切片不改通用拾取所有权。
