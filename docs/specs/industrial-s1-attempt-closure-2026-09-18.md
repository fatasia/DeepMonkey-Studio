# 工业导入 S1：统一任务与 attempt 发布

2026-09-18。上传、HTTP、MCP 和 SDK 使用同一转换任务服务；任务记录进入现有 MetadataStore，模型指针和成功任务在同一次元数据事务提交。本文记录本轮证据，不替代工业格式权威计划，也不表示七个方向已全部完成。

## 已实现

- 上传返回 `conversionTaskId`；模型导入走注册的 adapter。持久化 queued 后才调度，幂等提交支持重复请求重放和冲突检测，未持久化 reservation 不对查询暴露。
- 每次执行使用独立 attempt 目录，成功前不发布 artifacts 或替换模型 manifest；转换失败、取消、对象存储失败、数据库提交失败均保留旧 ready 模型。重启将未结束任务明确终止，新请求创建新 attempt。
- 实际输入大小、SHA-256 校验；缓存缺失时从现有 ObjectStore 恢复，截断、超量、错误哈希和流失败均拒绝。没有新增存储系统或改变 Postgres/MinIO 分工。
- 对象键、文件相对路径和 realpath 一致性检查；拒绝 `..`、反斜线和 junction/symlink；manifest 与 sidecar 通过同一取消/大小约束上传。每项产物记录实际大小、SHA-256，GLB 额外做几何审计。
- SourceBundle 与质量报告绑定输入哈希；inspect/preview 不得激活 ready。失败任务保留已验证的来源和质量诊断，不暴露未提交产物。现有 JT/X_T 受限 reader 行为保留，没有将其升级为 visual-complete。

## 验证

### 13:00 终态重放保护

真实 OBJ 上传/转换夹具复现：相同 succeeded 任务再次提交不同 `manifestUrl`，原实现会替换已发布地址；旧任务在新 attempt 完成后的纯确认重试又会被误判为竞争任务。本轮修复终态不可改写：完全相同任务及相同已存模型字段重放为无写入操作，终态任务记录或模型更新不一致时拒绝。旧任务纯确认不抢回新 attempt 指针。failed/cancelled 同样不可改写，保留旧 ready 模型；重开存储后再次核对结果。

修复前两个新增回归真实失败；修复后 6 文件、40 项针对回归通过，API TypeScript 通过。该保护在单实例元数据事务内生效，不替代 PostgreSQL 跨实例 CAS 和租约；后两项仍未完成。

2026-09-18 10:16 API 最终全量：201 文件通过，1279 测试通过、4 跳过；API TypeScript 检查通过。attempt 边界、持久化与质量专项 18 测试通过；manifest 缺失/不一致负例加入后，持久化专项 7 项通过，JT/X_T/robot/assets 相关 26 项通过。质量/SourceBundle contracts 专项 21 测试通过。

新增专项包括：真实 Windows junction 越界、路径穿越、manifest 取消、晚到执行器回调、超时、不合作执行器取消、重复对象键、并发幂等 reservation、重启恢复、对象/元数据提交失败、输入缓存恢复和错误字节流。产物测试逐项核对对象键、上传调用、物理字节长度及 SHA-256。

## 3DM 实际结果

MechPartA 来源：固定 openNURBS `v8.35.26251.13001` 的 V4 样本，源 SHA-256 `a1b0ef69925b5d9223a7d797033055bb766842768a96f7713e1ecaec2763bb31`。本轮只修改边界审计，拒绝空边界、单点、非法索引、非有限坐标、零长度边和重复面；新增 8 项负例。与真实平面重建组合运行共 10 项通过。

真实输出仍为 41 面、49 条未认证共边、7 条 seam 通过；304 条来源引用，最大 reference 误差 `5.402578411571407e-15 mm`，最大 mapped 误差 `0.00011604421402500306 mm`。GLB 为 48,067 顶点、85,632 三角形，SHA-256 `82a84b95a08661260f3e2a42965b58698d70868245abe9a27efe6edb9a006523`，状态保持 `partial-geometry-preview`。

调查产物位于 `test-output/industrial-3dm/plane-reconstruction-2026-09-17-v1/survey/`。49 条边中 45 条尚未认证可修复；4 条为 trim 顶点预算失败（35、36、40、41）。主要缺口为非线性 UV trim、多段 Bézier 区间跨 knot、不同次数和重参数化证明。放开非有理等曲线入口的试探没有减少未认证边，已撤回。没有放宽 0.01 mm 预算或改变已发布几何。

后续补入 authored C0 Bézier 链跨 knot 精确裁剪：逐段齐次 de Casteljau，保留源 knot 和次数，不近似。数学与真实圆柱/平面回归共 11 项通过；加入 8 个单侧认证、不许单侧焊接断言后，真实平面回归 2 项再次通过。真实调查中 8 个单侧等曲线证明从不支持变为通过：edge/face 为 44/12、47/14、53/18、56/20、69/27、71/28、79/31、81/32，连续误差上界 `2.0381e-15` 至 `3.0611e-14`。各边的另一侧仍缺独立证明，因此没有焊接这 8 条边，49 条未认证总数不变，导出 GLB SHA-256 保持上述值。

## 尚未关闭

- 执行器仍在 API 进程中；timeout/cancel 隔离发布和晚到回调，但不是 OS 级 CPU/内存限制，也不能强制停止同步解析器。多实例租约/worker 隔离与 crash 注入仍需独立实现和验证。
- SourceBundle 当前记录工业根输入，未实现全部装配外部引用闭包及每个格式完整质量报告；没有完成跨项目缓存签名、自动 retry 编排和孤立 attempt 清理策略。
- 历史受限 reader 可用不等于通用完整 reader；X_B 和不支持的 JT/X_T profile 保留来源并进入 inspect/waiting，未启动配置的商业转换回退。
- 3DM 的 49 条共边连续性仍需有界的源曲线/曲面重建证明；本轮审计补强不计作 visual-complete。
- 七个工业方向的真实样本、开源依赖分发审计、完整浏览器验收和性能矩阵仍按权威计划继续，不以此次 S1 测试替代。
