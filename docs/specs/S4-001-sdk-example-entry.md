# S4-001 文档中心可运行样例入口

状态：本入口已验收（r13 同一冻结 bundle 两轮正式门禁及截图亲审通过，证据见 `docs/sdk-example-entry-verification-2026-09-06.md`）。

## 最小交付

复用现有文档中心、`studio-api` 指南、脚本文件列表、Worker 运行合同与 `useBehaviorDraft.addScripts`。新增一篇 SDK 样例指南及三个可浏览、复制、修改并试运行的只读样例：生命周期、变量读取、场景事件。

执行链：当前二维/三维编辑器 → 文档 → 选择样例 → 确认目标项目 → 新建独立文件 → 修改 → 试运行 → 按现有保存设置保存。新增不自动运行或发布；自动保存已开启时仍按原产品设置保存，不承诺零服务器写。

## 职责与边界

- `docs/sdkExamples.ts` 是展示与插入源码的唯一来源；仅调用当前 Worker 的 `studio.version`、`studio.log`、`studio.getData` 和生命周期 `ctx` 事件上下文。
- `behavior/sdkExampleInsertion.ts` 只生成文件：独立 ID、规范化同名编号、API 1.0、Worker、scene 挂载、最小声明。未知样例或 ID 碰撞拒绝。
- `DocsSdkExamples` 负责浏览、源码复制、上下文说明、确认/取消、重复点击锁和错误反馈。
- `useSdkExampleNavigation` 将请求绑定到进入文档前的用户/项目/应用身份，导航回同一编辑器；请求只消费一次，失效后清除。
- `SceneBehaviorPanel` 由并行脚本任务接入请求，复用已有草稿保护：有名称草稿保留，无名称草稿阻止，失败请求也消费，避免后续意外插入。
- `useAppNavigationController` 统一文档入口草稿保护；三维离开前捕获已有实时快照；返回使用原路由，不触发整页重载。

文档 CSS 复用 `base.css` 品牌、文字和表面令牌。沿用现有文档布局，补窄屏目录收纳，不引入组件库或运行依赖。
