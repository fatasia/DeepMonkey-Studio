## 四、可证伪条件(违反任一则本估算失效,需重估)

1. 真实 JT 纹理样本 / X_T 内置 key 匹配样本 / 真实 OPC UA broker 与 PLC **获取失败或超期**——T22/T24 的对应验收项无法闭环(当前已有精确缺口记录与来源清单)。
2. GPU 域(T06/T07/T09/T10/T20)单项真机配对平均返工 ≥2 次(本次会话 GPU 域单次通过率 100%,若节奏劣化则 C 阶段上界失效)。
3. 并行通道从 5 降为 ≤2(人员/代理配额),吞吐按比例折减。
4. 出现跨包阻塞链断裂(如 T12 几何链阻塞 T17 CAD→collider 与 T22)。

## 五、与旧估算的关系

旧全量估算 4–7 个月基于"W0–W4 波次串并行 + 无 24 包外新域"。本重估变化:①功能先行排序消除了波次等待;②T24–T32 九个新包并入(净增约 1.5 周已含);③实测吞吐证明切片粒度(20 分钟–4 小时/条)比整包粒度管理效率高一个量级。**6–9 工作周取代 4–7 个月作为当前计划口径**;两者差异主要来自管理粒度与并行度,而非范围缩减——范围未减,逐包剩余清单见第二节。

## 六、终版回填(2026-09-28 收官)

最后 8 条线(T02 GI 参考/T03 反射整包化/T06 虚拟纹理/T09 天气/T18 布料软体/T12-UV/T12-几何/T14-编辑器/T17-collider/T24-OPC UA/T26-HLOD)收官,实测交付总数达 **44 条切片线**。对第一至五节的修正:

1. **速度结论维持**:44 线/约 34 小时 ≈ 9–12 线/天,与底稿 8–11 线/天一致,6–9 工作周估算**不变**。
2. **覆盖面修正**:有报告的包从 20 扩至 **33 个**(T00–T32 中仅 T10 硬件 RT、T23 工业仿真校准两包未开工——均为 W3/W4 重域;T17 达到"核心完成(附边界声明)",T12/T24 接近)。
3. **新增量化缺口**(已入各报告 GPU 联测清单):T02 需 ≥32 方向/探针(现行 16 临界不足)、T05 的 10k 降比需重定义口径(提交架构 O(批次))、T07 响应掩码渲染器供给未接、T26 代理网格几何、T24 SubscriptionTransfer 与真实 PLC。
4. **跨线质量机制有效**:44 线中 3 处由并行线诚实报告暴露他线缺陷(conversion dataDir/lifecycle cfg/架构边界),均当轮修复;1 处 T06→T04 同机制风险移交已修。
