# 3DM 源共边：统一插结点控制网

MechPartA 的 edge83 已使用源 NURBS 共同基函数证明并统一边参数链。完整面覆盖仍为 41/41，共边不一致从 54 降到 53，7 条周期自缝保持通过；整件状态仍为 `partial-geometry-preview`。

## 根因与算法

- edge83 的 C3、face11 平面 C2、face34 二次×一次曲面等参线分别有 10、11、9 个控制点。它们对同一源曲线使用了不同插结点，不是源几何冲突。
- 将定义域归一化，按两个源 knot 向量的精确值和最大重数取并集，使用齐次 Boehm 插结点。禁止近似合并 knot、拟合控制点或移动旧网格点。
- 当前入口只在控制点数不同时使用共同基；原等控制点路径和 C0 knot 位移证明保持不变。接受正权、夹持端点、次数 1–8；内部重数不得超过次数，最多 128 个内部 knot、256 个控制点，越界拒绝。
- 在共同基下分别归一化两组权重。控制点位置项取最大欧氏距离；权重项为 `2 R max|wa-wb| / min(wa)`，其中 R 是第二组控制点相对其首点的最大半径。后者来自两个正权凸组合的分子与分母差界，不以稀疏采样代替连续证明。
- 证明仍消耗原源身份预算 `min(1e-10, sourceTolerance + 1e-12)`；edge83 的源声明容差为 0，保留既有数值身份余量 1e-12。物理总预算仍为 0.01 mm。

复用原共边参数并集、源 PointAt 插点、法向计算与事务式局部重三角化。失败时不提交任何面修改；原顶点、原法向全部保留。
