## 2. 修复内容(diff 说明)

### F5-GI-1a:`deepGiVisibility` 均值分支合同收紧

文件:`packages/deep-engine/wgsl/probeClipmapSampling.wgsl`(单源)→ `pnpm wgsl:sync` 重生成
`src/lighting/probeClipmapSamplingWgsl.ts` + `.sha256` 夹具;TS 镜像 `src/lighting/probeClipmapSampling.ts`
(`visibilityWeight`);Rust CPU 镜像 `deep-engine-native/src/probe_gi_grid.rs`(逐式同步)。

- 旧合同:`distance <= meanDistance → 1.0`(无条件);否则 `max(occlusionFloor, Chebyshev(δ=r-μ))`。
- 新合同:均值分支**仅在记录自证封闭包络时适用**(`floor ≤ 0.001 && variance ≤ max(μ², spacing²)`);
  天空探针(floor>0)一律走双向 Chebyshev(`δ=|r-μ|`);floor 改为"探针内容环境光占比"的内容限定符,
  **不再作 receiver 链路权重下界**(否则天空探针隔墙保底漏光,与均值分支同型缺陷)。
- 合同原意(a6e8a304 `probeOcclusionRayExtension` 估计口径):μ = 命中射线距离均值(不含 miss)、
  σ² = 命中距离总体方差、floor = miss 占比。均值分支的适用边界 = μ 能充当 receiver 链路几何上界,
  这只在"逐方向都有命中且离散有界"时成立;薄墙在 μ 内但被中间几何遮挡时必须拒绝。
- 不回退论证:既有测试的记录全部 floor=0(封闭)或 μ=0(Chebyshev 路径),行为逐位不变;
  行为变化仅在 floor>0 的天空探针记录——恰为缺陷类。

### F5-GI-1b:捕获内核命中点补阴影射线

文件:`packages/deep-engine/src/rayTracing/probeRadianceKernel.ts`(头注释 + `probe_scene_radiance_batch` 主体)。

- 旧口径:"命中点不追第二次阴影射线"(F1 第一切片声明的边界)——封闭房间内壁按无阴影直射着色。
- 新口径:nDotL>0 的命中点向主光方向(`params.lightDirIntensity.xyz`,producer 侧已归一)补一条
  遮挡射线(复用 `probeTraceClosest`,origin = hit + normal×0.002 + lightDir×0.002,tMax = params.tMax);
  遮挡则该方向贡献 0(其一跳切片不追第二次反弹,能量向下取整);阴影 trace 溢出(负 t)保持无阴影项,
  不改变主射线的整探针 fail-closed 语义。
- WGSL 经独立 naga 校验器验证(validation successful);生产者/打包测试全绿。
