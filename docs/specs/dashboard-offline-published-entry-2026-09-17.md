# 离线包入口使用同一发布快照

2026-09-17。正式 Dashboard 内容编译、发布候选和单 EXE 下载链已存在，本片修复作者端接线，不新增编译器。

根因：离线包对话框读取已发布版本的 ID/revision，却从当前草稿选取入口页。发布后编辑草稿首页或删除页面，会混用两个版本，导致准备请求被拒绝或按钮消失。公共应用接口已经返回完整发布记录，原 Web 类型未保留 document。

现在入口页、publicationId 和 revision 均来自同一响应的已发布 document。没有 profile 时使用该发布记录的第一页；profile 指向无效页或缺少 document 时明确提示，不从草稿补页。对话框按项目/应用身份重新挂载，沿用请求取消和 ticket 防护。

另修复下载失败路径：读取错误 JSON 是异步操作，读取后再次检查请求 ticket，旧下载错误不能覆盖新候选的准备状态。

事件处理器测试覆盖草稿改首页/删页、取消后的迟到结果、编译失败重试、发布首页缺失/无效、无 profile 以及旧下载错误迟到。测试替换 React 状态调度及宿主，不替代浏览器与真实 EXE 验收。沿用既有界面样式；浏览器会话不可用，本片未完成截图视觉复验。

未改公共 `api.ts`、服务端、原生端、共享台账或 CHANGELOG。

验证：入口与状态机 16 项通过，Web 全量类型检查、repository governance、修改文件 diff 检查通过。组合内容编译回归最后一次为 45 通过、1 失败：并行背景层修改后，`compileDashboardRasterContent.test.ts` 的旧快照断言仍把 `nodes[0]` 当内容层，已交回该文件维护代理；本片没有修改该编译器或测试。
