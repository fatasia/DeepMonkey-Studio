## 每项完成定义

1. 源码、类型、单元/集成测试和相关构建通过。
2. 在 Browser 或 Native 真 GPU 上运行，不以 mock 或静态计划代替。
3. 失败、取消、超时、迟到结果、device loss 和资源回落有断言。
4. UI/画质改动完成至少两轮真实浏览器截图和运动场景复核。
5. 记录 build/asset hash、adapter/backend、性能采样窗和未覆盖项。
6. P0 通过前默认 Three 不变；设置切换失败必须回到可用后端。

提交前的代码预检统一执行 `pnpm gate:deep-p0`；它覆盖 Deep Browser core、Native Player 与 Studio 类型/测试/构建。真实 GPU、三项目和两轮视觉验收仍须另行留证，不能被该命令替代。

完整项目入口是 `pnpm studio start web` 和 [http://127.0.0.1:5173](http://127.0.0.1:5173)。`http://127.0.0.1:5291` 仅为专项 Lab，不作为 P0 交付入口。
