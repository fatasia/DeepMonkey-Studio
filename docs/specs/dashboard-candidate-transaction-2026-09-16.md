# Dashboard 页面候选事务

状态：已完成 CPU 候选事务子片；C1 浏览器实际组合绘制仍为本轮待办。

`DashboardCandidateController` 将 v5 包资源准备、页面内容、图表更新和模拟游标放入同一候选。所有资源准备完成后才调用宿主离屏绘制，绘制成功后同步切换可见页面。宿主缺失时返回 `requires-host`。

- 同时最多保留一个已提交页面和一个准备中的 GPU 候选；额外请求返回 `busy`。取消后等待实际准备结束再回收，避免释放仍在使用的资源。
- 图表数据更新和模拟时钟要求匹配包 hash、页 ID、generation、device epoch；过期事件在分配前拒绝。
- 候选使用独立模拟游标。第二张图更新失败、离屏绘制失败或显示提交失败时，原页面及游标保持不变。
- 同包切页保留有界 CPU 图表状态；换包清空旧缓存。提交期间禁止重入发布或销毁。

验证：基于 `8f2bd36` 独立导出 9 个文件，运行包/图表 302 项测试及核心、Lab 类型检查通过；主树合入后运行包和游标专项共 305 项通过，双类型检查通过。覆盖资源屏障、迟到事件、设备变更、失败回收、重入和切页恢复。

该子片要求宿主提供真实 `prepare`、`commitVisible` 与 `release`。CPU 测试的宿主替身用于事务断言，不能作为浏览器像素或 GPU 验收证据。真实 WebGPU 宿主另行接线验证。
