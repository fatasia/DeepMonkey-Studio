# Native 作者点光六面阴影（2026-09-18）

点光 castShadow 已进入作者编译、Native 六面投影及离线发布链，复用既有深度数组、GPU 剔除和事务。

## 实现

- recipe v10 / 环境 v5 / `deep.scene.point-shadow.v1`，最多 1 个投影点光与 4 个投影聚光并存；主方向 CSM 另占 4 层。超量作者请求和运行包均拒绝，旧 v4 仍不接受点光投影。
- Frame v5 为 1904 字节，保留 v1–v4 前缀；局部矩阵上限 10，动态对齐步长 2048。点光六面按 `+X/-X/+Y/-Y/+Z/-Z` 存储，接收端按主轴选面；同源位置、距离与浮动原点用于出光和阴影。距离 0 的阴影远面仍为 500。
- 同一 ShadowViewSource 为每个面提供视锥、透视 LOD 和 caster dirty key。脏掩码从 8 位扩至 16 位，最大 14 层；2048² Depth32Float 最多 224 MiB。相机/窗口变化只更新方向 CSM，不扰动局部层。
- castShadow / receiveShadow、已有遮罩与双面管线共用原机制。材质完整组合矩阵仍需后续实测，不将共用代码等同于已验收全部组合。
