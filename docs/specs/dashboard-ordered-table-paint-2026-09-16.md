# Dashboard 表格有序绘制

状态：已完成冻结表格背景、文字和首列遮挡的有序绘制子片；生产页面自动冻结与完整交互仍待接线。

冻结布局可携带完整的 `paint` 排列，逐项引用已测量的背景或文字。编译器按排列生成连续图层，不再把所有背景提前到所有文字之前。省略该字段时保留原有背景后文字的兼容行为。排列必须覆盖每个对象且不得重复，最终图层继续受 Dashboard 的 128 节点预算约束。

DOM 捕获适配器只接受一个现有 `freeze-first-column` 表格，核对实际 sticky 层级、DOM 顺序和每个可见冻结单元格的背景。支持现有样式使用的无模糊、无扩散单侧 1px 阴影；其他 stacking context、定位和阴影仍明确拒绝。

验证：59 项独立测试和 TypeScript 检查通过；主树相关 32 项通过。真实浏览器在横向滚动 160px 后捕获到 `auto/2/4` 层级对应的十笔背景/文字顺序，冻结首列仍覆盖后方内容。该浏览器夹具验证捕获合同，不代表生产 Dashboard 已自动调用适配器。
