# Dashboard 冻结数据内容

状态：已完成 C2 数据编译子片；正式发布与完整呈现仍为本轮待办。

KPI 和表格编译复用 Web 的数值格式、聚合、排序与分页逻辑，输入必须提供带内容 hash 的冻结 metric、明确字体资源和实测排版。编译结果保存文字 producer、字形、像素及字体身份证据。图表将明确的数据快照转换为 ChartIR，目前支持 bar、line、scatter 与不超过 20 类的 pie。

文字保持像素尺寸，通过独立节点裁切小数尺寸文本框；连续同裁切层合并，作者节点及图层顺序保持不变，最终仍受 128 节点和资源预算约束。颜色路径使用线性 RGB，字体像素使用 sRGB。图片继续按作者 fit 语义缩放。

`captureDashboardDataLayout` 读取实际 DOM 边界、字体、换行和祖先裁切。浏览器夹具验证 0.75 与 1.25 倍缩放下的逻辑尺寸及小数裁切。自动匹配生产页面的全部角色和正式数据绑定尚未接线。冻结首列需要有序背景/文字合同，本片明确阻断。

验证证据：

- 主树 Web 类型检查通过；初次合入 145 项测试通过。
- 小数尺寸修复的 5 项对抗回归修前失败，修后通过；独立 `a2403d7` 导出加本片通过严格类型检查、149 项测试，两个真实字体集成测试因缺少显式字体环境跳过。
- 主树真实字体文字/图片集成通过；KPI、表格和图表同页的 12 次实际字体请求独立运行通过，耗时约 54 秒。全套并行时该集成曾超过 60 秒；单用例预算改为 120 秒，单次 producer 超时保护不变。
