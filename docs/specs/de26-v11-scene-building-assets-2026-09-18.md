# DE26/V11 场景搭建素材库

用户目标：在场景编辑器中预置道路、地面、围栏、绿化等模板素材，拖拉拽即可搭建场景。归属 DE26/C07 场景子切片，不另建素材管理器、建模内核或场景状态源。

## 使用流程

场景资源面板选择“环境搭建” → 拖动带缩略图的素材 → 场景中显示落点预览 → 松手创建 → 就地调整尺寸、方向、材质和重复间距。常用操作不跳转到参数化建模页面；点击素材后放置作为拖拽的键盘/无拖拽替代入口。

## 首批素材族

| 类别 | 模板 | 场景内可调参数 |
|---|---|---|
| 道路 | 直路、弯道、T 字与十字路口、人行道 | 长宽、转角/半径、朝向、路面材质；连接点对齐 |
| 地面 | 混凝土、沥青、铺装、草地面片 | 长宽、标高、材质平铺尺度 |
| 围栏 | 网片/栏杆、立柱、出入口段 | 段长、高度、间距；沿直线/折线连续铺设 |
| 绿化 | 单树、灌木、绿篱、绿化带 | 尺度、间距、数量、排列；固定种子保证重开一致 |

先补真实场景需要的代表模板，再补变体；不把模板数量当验收。几何、缩略图和运行时实例必须一致，不能以简单方块代理冒充最终素材。公开素材保留来源、版本、hash和许可，私有素材不进仓库。

## 素材获取

用户已授权缺少素材时直接从网上下载，山海鲸、捷码作为素材分类、外观与拖放体验的对标。先查仓内与本机缓存，再查可下载素材；有明确可用授权的资源直接下载、固定版本和 SHA-256，不把所有模板都改成自建任务。产品展示图库不自动等于可再分发素材，未确认使用权的文件不进入分发包。

入库走既有资源审计与发布流程：记录来源 URL、作者、许可/署名、文件版本与 hash；校正单位/轴向/落点，打包纹理闭包，生成缩略图和 LOD，登记连接点/实例化策略。道路、地面、围栏、绿化必须在场景内实际拖放验证，不能仅因模型文件可打开就标为可用素材。

## 复用边界

- 素材发现复用现有场景资源面板和 `industrialPrefabCatalog`；`BuiltInAssetBrowser` 仍只负责全局浏览/导航，不复制编辑逻辑。
- 参数、版本、派生资源复用 `parametricGeneration`、`parametricCadRuntime` 和预制件实例合同。现有参数化模板主要是机械零件，不能据此宣称已有园区环境库；简单铺装/重复实例不强制走 CAD 内核。
- 落点使用现有相机/拾取/世界坐标服务，变更进入既有场景插入、命令与撤销通道；B01 是状态权威。资源到三维画布的拖放接线须实际核验，图层拖动不算素材放置。
- C07 负责确定性派生、内容缓存、模板版本；B01/B02 负责场景状态与投影；G03/H07 负责既有发布与更新。同一成果只在 C07/V11 记一次完成。

## 必须通过的操作验收

1. 四类素材各选一个，在真实编辑场景里拖入、贴地放置、旋转/缩放、复制和删除；可选择网格或连接点吸附，也可关闭吸附。
2. 道路连接点能对齐，围栏/绿化可连续铺设；一次铺设视为一次撤销事务。Esc/移出画布/加载失败取消预览，不残留对象或资源。
3. 保存→刷新→重新打开保持 ID、参数、位置、材质和排列；参数更新不覆盖用户对其他实例的修改。单位、标高、大坐标与 D04 坐标规则一致。
4. 已批准模板进入既有 Web/Native 离线发布链；缺资源、目标不支持或超预算显示具体原因，不静默替换成代理。
5. 两轮实际浏览器截图与操作覆盖双主题、标准/窄窗、缩放/DPI；检查拖放遮挡、无落点、长标签、加载/错误/空态。新增视觉遵守 `design-taste-digitaltwin`，令牌来自 `base.css`。
6. 重复围栏、树木优先共享资源/实例化；记录选定真实场景的对象数、帧时间和资源峰值。大批量输入有预算、取消与错误恢复，不以降低素材质量换通过。

实现状态：范围和验收已确认，现有模块已初步核对；场景搭建新功能尚未据此标为完成。V12 不建设，不引入扫描对照或 Gaussian Splatting。
