- `updateModule(module)`:运行中/暂停热插——旧脚本 onStop → 新模块 initialize → ready 后恢复热插前形态(running 即发新 onStart/onData;paused 挂起等 resume)。**场景快照(latestData)、数据流与调度时钟保留**——只换行为逻辑不重置场景。
