# Dashboard Web 静态包：生产接线与下载入口验收

供已发布 Dashboard 离线交付使用。API 生产构建现包含静态运行时，下载入口只展示部署实际提供的格式。

## 本轮交付

- `dashboardWebStaticDeployment` 按已发布项目、应用和 revision 核对身份，复用现有候选包与资源读取链。
- `dashboardWebStaticFiles` 为单文件和总资源设置读取预算，检查目录穿越、符号链接/junction、文件增长与取消；字体按许可清单收集。
- API 构建附带 `dist/dashboard-static`，包括运行时页面与许可证文件；命令行打包与生产路由共用包生成器。
- 下载弹窗增加部署格式列表、下载成功/失败反馈、取消后重试、状态图标与文字、完整 ID 提示、本地分钟时间；Tab/Shift+Tab 留在弹窗，Esc 关闭并恢复焦点，尊重减少动效设置。
