## 已有(不重建,Web 侧三项全覆盖)

1. **告警挂载已实现**:`alertAudioDirector.ts`(T29 端口化调度器)——AlertEvent 流按 AlarmBinding 规则映射为每台设备告警声启停,经 AlarmSink 出口挂到 modelId 声源(startAlarm/stopAlarm 告警音独占+清除恢复);自带泄漏/幂等 node 测试。
2. **ambient/空间播放合同已接**:生产路径=viewerEngineSpatialAudio(THREE.PositionalAudio 挂模型原点、监听器随相机、手势解锁、buffer 加载缓存单一出处);`spatialAudioGraph.ts` 明确纪律"不重造播放引擎",只提取 BufferSource→Gain→Panner 参数映射供离线验证与释放证明,Panner 参数与 THREE 桥一一对应、音量口径共用 effectiveLinearVolume(防第二份映射)。
3. **多声源混音**:Web 侧每模型一个 PositionalAudio 声源=天然 Web Audio 图混音;离线混音验证走 spatialAudioGraph(OfflineAudioContext)。
4. 附属:`spatialAudioAttenuation`(衰减口径)、`alertAudioRules`(快照差分)、`offlineAudioAudit`(离线审计)齐备,各带测试。
