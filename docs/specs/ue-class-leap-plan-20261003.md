# UE 级六专项 + 全套编辑器 设计方案(2026-10-03,最高优先级)

> 目标:硬件光追、Lumen 级全动态 GI、Nanite 级虚拟几何、VSM 虚拟阴影、MegaLights 万灯、物理广度**一次性达到行业主流级别**,并给出全套编辑器设计方案。
> 硬门槛(不可违背):自研/开源内置、本地离线、禁商业 SDK/云转换/许可证服务器;Web(WebGPU)与桌面(Tauri+Rust/wgpu)双形态。
> 诚实口径:vs Unity/UE 零基准禁定量;每个专项立**自家绝对指标验收门**,达标即"行业主流级"的可证伪定义。

## 0. 平台现实与总体架构决策

| 事实 | 对方案的影响 |
|---|---|
| WebGPU 标准无硬件光追 API;wgpu(native)已有实验性 ray-query(VK_KHR_ray_query/DXR) | 光追分双通道:**Web=compute BVH**(仓内已有 rayTrace/TLAS 批处理基座),**native=wgpu RT 特性**(不可用则同 compute 路线回退) |
| WebGPU 支持 compute/storage 写入、f16、(实验)subgroups | ReSTIR/VSM/Nanite 页调度全部可做,无需降级 |
| 引擎已有:探针 GI 体积+SDF 资产线(A2)+meshlet/簇 HLOD(G1/T26)+CSM 级联+Forward+ 簇光+XPBD GPU 切片(布料/流体烟)+命令层/事务/检查点 | 六专项全部**在既有基座上升级**,不是从零建设 |
| 渲染主通路:PbrRenderer(Forward+) | 新增通路以"pass 插件"接入 frame-graph,不推翻 Forward+ |

**里程碑口径**:每专项 M1=核心可验(单场景闭环+定量门)→ M2=主流级(达标验收门)→ M3=超越(扩展)。六专项+编辑器可 3 路并行(渲染互斥串行,物理/编辑器独立)。

## 1. 硬件光追(双通道)

**行业主流级定义**:实时混合管线中,阴影/GI/反射至少一项由光线追踪驱动;离线路径追踪达到降噪后可直接出图。

### 设计
- **BVH 层(共享)**:BLAS=meshlet 包(per-meshlet 4/8 叉树,构建走 G1 meshlet 管线);TLAS=实例Transform 批(已有 `rayTraceTlasBatch` 基座)。**增量更新**:实例动→只重写 TLAS;网格动→meshlet 级 refit(不重建)。
- **Web 通道(compute)**:WGSL 栈式 BVH 遍历(已有 CPU/compute 参考实现),f16 加速盒相交;输出 hit 信息供三种用户:①阴影光线(替代 CSM 的单级联硬阴影)②GI 探针遮挡(替代 SDF 遮蔽,见 §2)③镜面反射。
- **native 通道**:wgpu `ray-query` 特性(评估当前版本;不可用则 compute 同 Web)。DX12/Vulkan 后端在 Tauri 壳内直跑。
- **降噪**:时域累积(复用 T07 时域重建)+ SVGF 简化(边缘感知的方差引导滤波,自研)。
- **验收门(M2)**:①1080p/1000 对象场景,RT 阴影+GI 混合帧 p95 ≤22ms(Web compute)/≤14ms(native RT);②路径追踪 1280×720 采样收敛 RMSE ≤0.02,降噪后结构相似度 SSIM ≥0.95(与离线参考比);③万三角形级动态网格 refit ≤2ms/帧。
- **M1(2 周)**:compute BVH 遍历打通 → RT 阴影 demo pass(单光源硬阴影替代单级联)+ 帧时证据。
- **依赖**:G1 meshlet(已有);降噪复用 T07。

## 2. Lumen 级全动态 GI

**行业主流级定义**:无烘焙,动态时间天光+动态光源+动态几何下,间接光无可见延迟级跳变;封闭房间无漏光(封门哨兵既有口径)。

### 设计:**混合三级 GI(类 Lumen 软件模式,全部平台可达)**
1. **静态遮蔽层**:场景 SDF(A2 资产线)+ SDF 追踪 GI(天光遮蔽、静态反弹 1-2 bounce,预计算+增量更新)——对应 Lumen 的距离场层。
2. **动态直接层**:屏幕空间 GI(SSGDI,复用 C11 SSR 的深度/法线缓存做半屏射线)覆盖动态物体近场。
3. **动态探针层**:现有 probeClipmap 升级——探针缓存由①②的输出**馈入**(不再只吃主光),F5 方向可见度门作为合成仲裁;探针时域滤波。
- **天光**:大气天空(atmosphereSky 已有)作为 GI 的无穷远光源,随时间动态更新 SDF 天光可见性(增量)。
- **漏光哨兵**:既有封门 leakRatio 测试扩展到动态天光场景。
- **验收门(M2)**:①动态昼夜循环场景(门内场景旋转/设备动)GI 无跳变(逐帧像素差 p99 ≤3/255);②三区 gi-on−gi-off 哨兵(既有 F5-L5 口径)通过;③白炉能量守恒(既有 C12)通过;④帧预算:GI 三层合计 ≤6ms@1080p。
- **M1**:SDF 遮蔽 AO(静态)+ 探针吃天光 → 一张动态昼夜对比图。
- **依赖**:A2 SDF 资产线(排最前);C11 深度缓存;probeClipmap。

## 3. Nanite 级虚拟几何

**行业主流级定义**:亿级三角形资产库、十万级实例场景,单 draw 流式渲染,帧率稳定;切档无"LOD 跳变"(几何渐变)。

### 设计:**集群级虚拟几何(簇/meshlet 与 Nanite 同构,Nanite=集群→三角形两步,我们先做好集群步)**
1. **离线**:mesh DAG 预处理(Rust 工具,新增 `deep-engine-native/geometry_dag/`):网格→meshlet 图→逐簇简化 DAG(Quadric 错误度量)+按屏幕误差排序编码,输出 `.dgc` 流式格式(分块、mipmap 式父子索引)。
2. **运行时**:页调度(复用 F3 虚拟纹理的页表/驻留框架,同一套 feedback/驻留预算)按屏幕误差+视锥+遮挡加载簇页;**可见性驱动软件光栅**(全屏 depth prepass + 簇级 burst 光栅,跳过被遮挡簇)——WebGPU compute 可达(现有 occlusionCulling/G1 剪影基座)。
3. **多 draw 合并**:GPU indirect(已有 lodIndirectDraws)按簇页分组,draw 数与场景规模解耦。
4. **过渡**:非 DAG 资产回退现有 HLOD/簇管线(兼容层),`rendererCapabilityManifest` 登记 `virtual-geometry`。
- **验收门(M2)**:①5 亿三角形单资产导入,显存 ≤1.5GB,帧 p95 ≤16.7ms@1080p;②20 万实例(合成)场景 draw ≤300;③相邻档位切换像素差 p99 ≤2/255(几何渐变);④页驻留抖动:帧间上传 ≤64MB/s 稳态。
- **M1**:DAG 工具链(单资产 1 亿三角形)+ 单页调度闭环 + 一段流式加载对比视频证据。
- **依赖**:F3 虚拟纹理页调度(需先完成,两专项共享基建);G1 meshlet。

## 4. VSM 虚拟阴影

**行业主流级定义**:16k×16k 等效分辨率的全场景阴影,近景无块状、远景无消失;动态物体阴影无长延迟。

### 设计:**页表化虚拟阴影(Clipmap 式三环绕,动态失效)**
1. **虚拟阴影图**:虚拟 16k² 页表(物理 2k²×4 atlas 页池,复用 F3 页池框架);三环 clipmap 围绕主视(近/中/远)。
2. **物化策略**:每帧按**屏幕像素投影误差**排序物化 Top-K 页(预算 ≤2ms);静态几何页带版本号,动态物体局部失效(页掩码)。
3. **采样**:页表查询 + 页缺失回退到上一档环绕(渐变,无洞);PCSS 软硬化随遮挡距离(接触阴影 C10 补近场)。
4. **替换关系**:替换现有 CSM 主阴影(级联保留为回退档,manifest 双档)。
- **验收门(M2)**:①同一 10 万对象场景,VSM vs 现 CSM:近景阴影边缘像素差(锯齿能量)↓ ≥60%;②阴影预算 ≤2.5ms@1080p;③动态设备(旋转/平移)阴影延迟 ≤2 帧;④零阴影洞(fail-closed 回退档覆盖)。
- **M1**:页表+物化+单环绕 4k 等效 → 对比 CSM 的边缘质量图。
- **依赖**:F3 页池;T04 分页阴影经验。

## 5. MegaLights 万灯

**行业主流级定义**:单场景 ≥5000 盏动态点/聚光(含 IES/面积)实时直接光,帧率稳定,光强分布无时间闪烁。

### 设计:**随机采样直接光(ReSTIR-DI 简化,全 compute)**
1. **灯光池**:统一灯光 buffer(点/聚/面积三型,面积光上限 8→**64**,常量与 LUT 已参数化);每灯:位置/类型/IES 索引/色温/功率。
2. **采样核**:像素级初始采样 RIS(候选 K=32 按辐射重要度加权)→ 时域复用(复用 T07 历史)+ 空间复用(5×5 波前)→ 着色。
3. **阴影**:采样灯的阴影光线走 §1 的 BVH(Web compute / native RT),每像素 1 条可见性光线(复用+噪声 подавление)。
4. **与 Forward+ 的关系**:≤64 盏场景仍走现有簇光(快路径);>64 或"万灯开关"走 MegaLights pass;manifest 登记 `meg lights` 双档。
- **验收门(M2)**:①5000 盏动态点光(含 10% 移动)1080p p95 ≤20ms(Web)/≤12ms(native);②与参考解(该场景离线聚合,512 采样)对比:直接光 RMSE ≤0.05,无时间闪烁(逐帧差 p99 ≤2/255);③面积光 64 盏 correctness(与 CPU 参考 RMSE ≤1%)。
- **M1**:灯光池+RIS 初始采样+单复用 → 1000 盏 demo + 帧时。
- **依赖**:§1 BVH 阴影光线;T20 曲线 LUT 经验。

## 6. 物理广度

**行业主流级定义**:刚体/关节/布料/软体/流体/车辆/绳索全栈 + 产品级调试器(录制/回放/跨端比对)+ 万级并行体。

### 设计(三条线)
1. **调试器(P0,最高频刚需)**:`physicsDebugRecorder`(确定性时钟驱动,每 tick 位姿/接触/穿透记录,ring buffer)→ 时间线 UI(复用 T28 调试面板/回放经验)→ 跨端位姿逐帧比对(复用 T17 黄金案例机制,WGSL/CPU/native 三方)→ 约束/接触/穿透可视化(现有 debugView 扩展)。
   - 验收:录制 60s@60Hz 场景无丢 tick;回放位姿与录制逐位一致;web/native 差异超阈值(1e-3)自动标红定位到 tick。
2. **GPU 统一 XPBD 框架(P1)**:把 T20 布料/流体烟切片泛化:统一"粒子+约束求解器"(距离/体积/形状匹配/流体密度约束),数据驱动场景类型;万级刚体聚簇(GPU impulse 求解,Rapier 负责交互体的窄相)。
   - 验收:10 万粒子流体 60fps@1080p;1 万刚体堆叠 p95 ≤16.7ms;与 CPU 参考能量守恒偏差 ≤2%。
3. **域扩展(P2)**:车辆(轮式悬架模型,复用关节+射线 Casting)、绳索(链式距离约束,XPBD 现成)、布料撕裂(约束断裂阈值)。
   - 验收:各域一条黄金案例(场景+指纹),进 `tests/` 与跨端对拍。
- **依赖**:T17/T20/调试面板(全部已有);Rapier 保持刚体窄相(禁替换)。

## 9. 风险与降级

| 风险 | 降级方案 |
|---|---|
| wgpu RT 特性不可用 | 全 compute BVH(Web/native 同路线),性能门用 Web 口径 |
| 亿级资产 DAG 工具链超期 | 先交付 1 亿级 + HLOD 兼容层(规模降一档,机制不降) |
| ReSTIR 闪烁 | 时域复用加强 + 采样数自适应;最坏回退簇光+万灯静态分批 |
| VSM 动态失效抖动 | 动态物体独立小 VSM(局部页),静态走大页 |
| 编辑器批次超期 | 每模块独立可交付,互不阻塞 |
