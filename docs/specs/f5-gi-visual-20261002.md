## 2. Harness 与场景构造(零产品代码改动,test-output/ 域)

- 入口 `f5-probe-entry.ts`:产品 `ViewerEngine`(作者 WebGL)→ `compileSceneRenderPacket`(场景全用 box primitives;注意 `primitiveGeometry('box')=BoxGeometry(2,2,2)`,scale 为半尺寸)→ 产品桥独立包路径(`authorRenderPacket`,与 `useAppRuntimeEffects` 同参)→ `switchTo("webgpu")`。1920×1080、`data-theme=dark`、base.css 令牌。
- 控制 API(`window.__f5`):GI 开关(生产 setter)、包替换(`DeepWebGpuBackend.prepareRenderPacket`——与发布同一实现)、探针重同步(`session.syncPacket`,与 `pbrRenderer.syncProbeClipmapSurfaces` 同构)、更新预算(`session.setUpdateBudget`,adaptive 档 64/48/32/16 同源)、相机微移、诊断读出。
- 薄壁场景:16×0.1 室外地面 + 0.04 壁厚封闭房间(墙 0.14..3.18 与顶 3.16..3.20 搭接)+ 门洞 2.4×2.38(唯一进光)+ 室内三尺度薄隔断(高 0.04/矮 0.04/微壳 0.02);阳光自门向入射(intensity 1.8,场景配置;默认 0.32/2.2 已由 z1 覆盖);GI 强度 0.8(harness 配置)。
- 动态场景:红墙(0.15 善壁)受阳光 → 白板红反弹;遮挡体 A(影子脱墙)↔B(挡直射);相机在左,两态同框。

## 3. 薄壁场景判定(两轮)

截图:`round{1,2}/thinwall/`(gi-on / gi-off / gi-on-restore / int-open-gi-on / int-open-gi-off / int-sealed-gi-on / int-sealed-gi-off / restored)。量化:`round{1,2}/metrics.json`。

- **视觉伪影:无。** 外景/室内机位逐张 Read:无漏光带、无黑斑(GI on 室内最低 ~105/255)、无 band/spots、TAA 稳定;GI on/off 全图 MAE 0.051,门内反弹差 +28..+44,天空参照零差异。
- **物理漏光:不过(F5-GI-1)。** 封门哨兵(门洞加盖 0.05 薄板 → 密封房间):
  - 室内 GI 增量(封门)≈ 开门口(intBackWall leakRatio 1.11;intPartition 无门口视线 leakRatio 1.006);
  - 室内 GI 增量(+62 B)超过室外全天空可见面(+43.7 B),违反物理上界;
  - 色偏可见:室内 GI off 暖调(132,125,109)→ GI on 冷调(177,176,171),被天空色洗白。
  - **机制**:房间外围天空探针 visibility 的 meanDistance 大,室内 receiver 距探针 < meanDistance → `deepGiVisibility` 走 `distance<=meanDistance` 分支返回 1.0 全权重,0.04 薄墙不构成 Chebyshev 拒绝。与 a6e8a304 的 0.1123% 漏光率(几何遮挡 fixture)不矛盾,但构成产品级场景反例:**天空探针 × 薄壁**组合绕过 alpha=0 拒绝链。

## 5. 产品发现(本刀产出,未修复)

1. **F5-GI-1(缺陷)**:薄壁+天空探针漏光——见 §3。建议后续方向:探针 visibility 对"capture 射线大量未命中几何(天空占比高)"的探针降权/标记,或薄遮挡体细化 Chebyshev(DDGI 论文已知弱点在本产品的具体形态)。
2. **F5-GI-2(接线缺口)**:Deep WebGPU 桥缺 scene-revision→probe session `syncPacket` 接线——`prepareRenderPacket` 提交后不重同步 probe 会话(`DeepWebGpuBackend.prepareRenderPacket` 无 `probeClipmap?.syncPacket` 调用,对比 `acceptSyncResult` :536 有);WASM 桥有 `refresh()`(useAppRuntimeEffects :680-697),Deep 桥无。后果:独立包路径下内容替换后探针继续用旧表面缓存,直到 GI 关/开重建。本 harness 以会话级 `syncPacket` 显式驱动补位取证。
