# 场景导演台：动画、时间线、镜头与漫游统一方案

日期：2026-09-13

## 1. 产品决策

三维编辑器只保留一个内容编排入口：`导演台`。导演台负责可发布内容的时序编排；编辑时的自由浏览仍由视口右上角的导航快捷入口负责，但不再保存另一套镜头或路径数据。

四个概念必须严格分开：

| 概念 | 用户心智 | 唯一编辑位置 | 是否进入时间线 |
| --- | --- | --- | --- |
| 导航模式 | 我现在怎样操作视口 | 右上角导航快捷面板 | 否 |
| 镜头 | 一个可复用的观察位置 | 导演台素材栏 / 右侧属性栏 | 作为镜头片段引用 |
| 漫游路径 | 按若干视点移动的一条路线 | 导演台路径编辑模式 / 右侧属性栏 | 作为漫游片段引用 |
| 动画序列 | 何时发生什么 | 底部可拖动、可缩放时间线 | 是 |

禁止继续存在“相机关键帧保存一份完整姿态、场景视角再保存一份完整姿态”的双写模型。镜头和漫游路径是素材；时间线片段只引用素材并保存片段级覆盖项。

## 2. 对标取舍

### Unity：采用专业编排模型，不复制编辑复杂度

- Timeline 用不同轨道编排多个对象，轨道包含可移动、裁剪和混合的片段。
- Cinemachine Shot Clip 引用虚拟相机；相邻片段是切镜，重叠片段是混合。
- Animation Window 只编辑单对象片段，Timeline 负责编排多个对象和镜头。

Deep Monkey 采用“轨道 + 片段 + 素材引用”的模型，但首版不引入 Animator、Playable Graph 或复杂曲线编辑器。

### 帆软 FVS：采用低门槛漫游路径流程

- 用户添加多个视点形成漫游路径，而不是直接面对一组相机曲线。
- 路径编辑时可直接预览，第一视角支持设置飞行时间。
- 镜头定位、路径漫游和触发事件面向业务用户表达。

Deep Monkey 采用“当前位置添加视点 → 调整 → 继续添加 → 直接预览”的路径流程，并允许把完成的路径放入时间线或绑定交互事件。

## 3. 信息架构与布局

视口右上角保留 ViewCube 和紧凑导航按钮。点击导航按钮仅展开：轨道浏览、第一人称、第三人称、碰撞开关以及高级移动参数。这里不再出现“保存镜头”“镜头列表”或“漫游路径”。

点击主工具栏的 `导演台` 打开底部面板：

```text
┌ 序列：主展示  [回到开始][播放] 00:03.20 / 00:30  [-][+] [适配] [关闭] ┐
├ 素材 ┬ 轨道列表             ┬ 时间标尺与片段                         ┤
│ 镜头 │ 镜头                 │ [入口全景────][设备特写──]             │
│ 路径 │ 设备 01              │       [启动动画────────]               │
│      │ 漫游                 │                    [巡检路径──────]     │
│      │ 事件 / 仿真（后续）  │                         ◆ 告警触发      │
└──────┴──────────────────────┴───────────────────────────────────────┘
```

- 面板默认吸附底部，允许拖动、纵向缩放和最大化；不再以随意浮动的小窗作为主形态。
- 左侧素材栏在窄宽度下收为图标；轨道标签固定最小宽度，时间区域横向滚动。
- 时间线只做结构与时序；选中素材、轨道、片段或视点后，详细参数统一进入现有右侧属性面板。
- 空态只给两个主动作：`新建镜头`、`新建漫游路径`；`新增轨道`始终可见。

## 4. 数据模型

下一版场景协议增加以下实体。命名可在实现时按仓库惯例调整，但引用关系不可反转。

```ts
interface SceneShot {
  id: string;
  name: string;
  camera: CameraState;
  createdAt: string;
}

interface SceneRoute {
  id: string;
  name: string;
  mode: "firstPerson" | "flythrough";
  waypoints: Array<{
    id: string;
    name?: string;
    camera: CameraState;
    durationToNext: number;
    easing: "linear" | "smooth";
  }>;
  collisionEnabled: boolean;
  loop: boolean;
}

type SceneSequenceClip =
  | { id: string; kind: "shot"; shotId: string; start: number; duration: number; blendIn: number; blendOut: number }
  | { id: string; kind: "route"; routeId: string; start: number; duration: number; speed: number }
  | { id: string; kind: "object"; objectId: string; start: number; duration: number; keyframes: ModelKeyframe[] };

interface SceneSequenceTrack {
  id: string;
  kind: "shot" | "route" | "object" | "event" | "simulation";
  name: string;
  muted: boolean;
  locked: boolean;
  clips: SceneSequenceClip[];
}
```

规则：

- 镜头片段引用 `shotId`；修改镜头后所有引用同步更新。
- 片段可选择“冻结副本”，需要时显式生成新镜头，禁止隐式复制。
- 漫游路径拥有视点和分段时长；时间线只控制路径片段何时播放及整体速度。
- 手动漫游参数仍保存在场景级 `navigationSettings`，但不作为发布序列数据。
- 片段引用的对象、镜头或路径被删除时必须进入可恢复的“引用失效”状态，保存前提示，不能静默丢片段。

## 5. 核心流程

### 5.1 建镜头并编排切镜

1. 用户在视口移动到目标位置，点击导演台素材栏的 `保存当前镜头`。
2. 新镜头立即出现在镜头素材列表，名称可就地修改。
3. 拖入镜头轨道或从“新增轨道 → 镜头”直接创建片段。
4. 两片段首尾相接表示切镜；拖出重叠区表示平滑混合。
5. 选中片段后，右侧只显示引用镜头、开始/持续、混入/混出和预览动作。

### 5.2 创建漫游路径

1. 点击 `新建漫游路径`，当前相机成为视点 1。
2. 移动相机后点击 `添加当前视点`，路径线和方向标记即时出现。
3. 选中两个视点间的段，在右侧设置飞行时间和缓动；全局选择第一视角或飞越。
4. 点击 `从当前视点预览`，可暂停、继续或 Esc 中断；中断后回到编辑前视角。
5. 保存后可将路径拖入时间线，也可在交互配置中作为“播放漫游路径”动作引用。

### 5.3 编辑时自由导航

- 轨道浏览、第一人称、第三人称是视口操作状态，不自动生成关键帧或路径。
- 只有点击 `保存当前镜头`、`添加当前视点` 或开启显式录制时才写入内容。
- 进入对象编辑工具时自动回到轨道浏览；切换前若路径正在预览，先停止预览并保留编辑状态。

## 6. 兼容迁移

旧 `cameraViews` 逐项迁移为 `SceneShot`，ID 原样保留。旧 `SceneAnimationState.camera` 按时间排序后：

1. 为每个唯一相机姿态生成迁移镜头；
2. 生成一条镜头轨道与对应镜头片段；
3. 相邻关键帧依据旧 `cameraInterpolation` 生成切镜或平滑混合；
4. 旧字段保留一个版本周期只读，保存新版本后不再双写；
5. 迁移前后在相同时间点采样相机位置、朝向和 FOV，误差必须在门禁阈值内。

现有对象关键帧先迁入对象轨道；导入模型自带 Animation Clip 仍由对象属性面板负责单片段预览，只有放入序列后才受导演台播放头控制。

## 7. 实施批次

1. **入口与职责收口**：主工具栏改为一个导演台入口；相机浮窗只保留导航设置；保存镜头与镜头列表迁入导演台；时间线继续可拖动缩放并保证新增轨道常驻。
2. **协议升级与无损迁移**：增加镜头、路径、轨道、片段合同和迁移器；补保存、刷新、发布、回放测试。
3. **镜头片段编辑**：支持拖动、裁剪、吸附、复制、删除、切镜与混合；选中片段联动右侧属性。
4. **漫游路径编辑**：视点增删、排序、路径可视化、分段时长、第一视角/飞越、碰撞和直接预览。
5. **交互与仿真接入**：交互动作引用镜头/路径；仿真作为只读轨道叠加，不修改原动画数据。

每批完成后都必须覆盖撤销/重做、空态、对象或素材删除、刷新恢复、发布回放、980px 窄窗、深浅主题、键盘操作和控制台零错误。

## 8. 首批验收标准

- 用户只看到一个“导演台”入口，不再需要在“动画时间线”和“相机与漫游”之间猜测。
- `新增轨道`在默认高度和 980px 宽度下均可见；面板可拖动、缩放、复位和关闭。
- 镜头只有一个属性来源；从镜头库改名或更新姿态后，时间线引用不失效。
- 漫游路径可在编辑界面直接预览、暂停和中断，路径不会污染手动导航状态。
- 选中镜头、路径、轨道或片段时，详细参数只出现在右侧属性面板一个位置。
- 旧场景打开后的相机动画与升级前视觉一致，保存刷新后不回退到旧双写结构。
