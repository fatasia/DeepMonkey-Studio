# 3DM 多段双三次曲面

日期：2026-09-17。MechPartB 无缓存重建达到 14/14 面；共边仍有 9 处不一致，保持部分预览。

## 支持范围与误差合同

接受 identity 参数、非有理、两轴三次、夹持端点及简单内部结点的控制网。
简单内部结点保证全域 C2；重复内部结点、有理曲面和非有限控制网明确拒绝。
没有新增 NURBS 求值器，也不把采样拟合当作源几何：位置直接使用既有原控制网求值。

通过 B-spline 导数公式 `(P[i+1]-P[i])*degree/(k[i+degree+1]-k[i+1])`
得到一阶和二阶导数控制网。非负基函数的凸包性质给出全域导数范数界。
沿用单块双三次的连续三角插值界
`(Muu*du² + 2*Muv*du*dv + Mvv*dv²)/8`，含混合偏导项。
无需复制插结点算法或构造新的 Bézier 几何；所有原内部 knot 直接并入 UV 网格，
三角形不跨越 knot。法线使用原一阶导数叉积和源面方向。

源局部物理预算保持 0.01 mm：10% trim、70% 插值，其余用于 UV 合并和 Float32 量化。
沿用源 trim、孔洞、源边身份和 UV 裁剪合同。遇到弯曲细长三角形的物理方向不一致时，
选择最长 UV 边，中点在源曲面求值，并同步细分所有邻接三角和源边列表。
不翻转单个三角掩盖问题，不增加 T 接点。最多 16 轮、100000 顶点、200000 三角，
奇异法线或无法收敛时拒绝；原连续误差界随细分保持成立。
