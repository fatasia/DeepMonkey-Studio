## 2. 交付物

| 文件 | 内容 |
|---|---|
| `apps/web/scripts/e4-maintenance-sweep.ts`(新增) | 场景 JSON → `parseSceneDocument` → `runMaintenanceClearanceSweep` → `formatMaintenanceClearanceReport`;内置验收双场景;`--scene/--out/--json`;退出码 0/1/2 |
| `apps/web/package.json`(+1 行) | `sweep:maintenance` 入口 |
| `test-output/e4-ui-20261002/` | progress-01/02/03 + builtin-report.txt/.json + example-scene.json + example-report.txt/.json |

**用法**(apps/web 目录):

```bash
pnpm sweep:maintenance                        # 内置验收双场景(过道人形 + 拆卸件抽取)
pnpm sweep:maintenance -- --scene s.json --out report.txt --json report.json
```

**场景 JSON**:movers 支持 `humanProxyBox / capsule / box / sphere / mesh`(mesh=顶点数组 →
`sceneMeshConvexShape` 生产通路,WeakMap 缓存);path 支持多路标 + 航向(绕 +Z);障碍支持
平移 + 航向;本体级红线覆盖;`sweepOptions` 透传。数值合法性断言全部委托 maintenanceSweep
域层,CLI 层只做结构分发(不重复造校验)。完整 schema 见脚本头注释。

**退出码语义(可作门禁)**:`0`=全部场景通过;`1`=存在场景未通过(碰撞/红线违规);
`2`=工具或输入错误。

## 4. 过程中修复的缺陷(同族排查)

1. `optionalNumber` 调用点与签名 `(record,key,label)` 不符(实参按 `(value,label)` 传):
   必填字段当场报错、**可选字段静默丢失**(红线覆盖静默失效)。签名改 `(value,label)` 单点
   修复全部 6 处调用;同族排查其余解析辅助无同型缺陷。教训:tsx/esbuild 转译不查类型,
   签名类缺陷必须靠显式 tsc 闭合(已纳入验收流程)。
2. `ConvexShape` 误从 maintenanceSweep import(定义于 convexDistance 未 re-export;
   `import type` 被 esbuild 擦除故运行时无感)→ 改从定义处 import(与测试同型)。
3. pnpm 10 字面透传 `--` 分隔符 → 解析器按 CLI 惯例跳过(1 行)。

## 5. 边界(诚实声明)

- 浏览器视觉闭环未做:装配形态为 CLI,无 UI 渲染面,浏览器闭环不适用;未来若做薄面板,
  需按 design-taste 闭环补齐;
- 帧时未测(指令禁测);GPU 未用,与并行线路零争用;
- JSON 障碍的 mesh 形态仅支持顶点数组直给,未接 GLB/场景文件加载(最小装配边界);
- 凸近似保守性(凸包 ⊇ 本体,净空只低估不高估)与离散化极限继承 E4/N10 口径
  (`e4-sweep-20261002.md` §3/§5),装配层未新增数值语义;
- `robotSweepCollision.ts` 工作树 M 状态为 E4 核心未提交的 framesAt 扩展,与本装配无关
  (git diff 已核对归属);未 commit/push。
