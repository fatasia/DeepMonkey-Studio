# Native 图表按系列增量准备

数据更新和缩放现在复用未变化系列的路径、命中索引和线数据点索引，减少动态图表的 CPU 准备工作。

## 依赖与事务

每个可见系列的依赖包含图表 ID、完整系列定义、所用坐标轴、对应 zoom windows、画布尺寸和实际 plot 矩形。数据事务额外提供本次变更的数据集集合。依赖一致且数据集未变时，复用原几何以及 Arc 持有的命中/线索引。

当前坐标域由各系列自己的数据及其坐标轴定义计算；未来若引入跨系列共享自动坐标域，必须把域依赖加入失效条件。

显示列表仍是扁平合同：复用的资源和命令从旧帧对应范围复制，新系列的输出直接移动进候选帧。缓存不再保留第二份路径，也不保留旧帧链；命中索引按系列从后向前查询，保持绘制顺序、前景优先和等距离选择规则。

折线绘制和原始点命中索引共用一次坐标映射，绘制降采样不改变被索引的原始行身份。

仅重新生成的路径更新资源 revision；整体帧 revision 继续随事务推进。隐藏系列不驻留在当前几何快照中，隐藏期间更新数据后重新显示会重建该系列。全源替换清空旧依赖，失败候选保留原快照。

## 验证

- 5项增量集成测试：独立数据集、轴缩放、resize、隐藏后数据更新、全源替换、重排和失败候选；6类系列的完整显示列表与原全帧渲染器相同，网格采样的 hit/pick 和 command target 与全重建相同。
- 1项所有权测试直接验证未变化系列的 Arc 索引共享，资源范围完整且不重复保留路径。
- 原几何/线命中/runtime/数据/状态/sim共33项回归通过，chart库15项通过，all-target检查通过。
- RTX4060 Laptop / Vulkan实际GPU测试11项通过；新增局部数据变化与全重建像素逐字节对照，以及拒绝旧版本后旧帧像素不变。sim初始+3次数据帧实际Presented，scopes/callbacks clean。

## 性能与剩余路径

基准使用 i9-12900HX、Release、1280×720、8系列×8192行；每组只改1个系列，预热5组，采样20组，交替执行顺序。计时包括ChartIR校验、几何、命中及线索引准备，不包括源数据事务、文字、GPU准备/上传或呈现。基准中同时保留优化前完整帧步骤，以检查初始全量准备是否退化。

最终同轮结果：

| 准备方式 | 中位 ms | P95 ms |
| --- | ---: | ---: |
| 优化前全帧步骤 | 11.3270 | 14.6453 |
| 当前全量准备 | 10.5913 | 14.3080 |
| 当前局部更新（重建1/复用7） | 3.8502 | 7.1539 |

局部准备相对旧全帧中位减少约66%，当前全量中位减少约6%。结果限于本机夹具和这次采样，不是端到端帧率提升。中间版本曾出现全量准备退化，合并重复映射后以上同轮对照通过；并行任务负载会影响绝对耗时，跨轮数值不直接比较。
