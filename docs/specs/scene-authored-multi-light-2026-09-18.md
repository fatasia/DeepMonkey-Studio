# Native 作者多灯交付（2026-09-18）

原 Engine 主线在已交付方向光上追加点光、聚光与额外方向光；复用现有 PBR/CSM，不另建渲染内核。

## 本次范围

- recipe v8、环境 v3、`deep.scene.multi-light.v1`。最多一个带 CSM 的主方向光加 16 个附加灯；附加方向、点、聚光消费颜色、全局/单灯强度、启用状态、世界位置/方向。点/聚光位置减场景浮动原点，旋转相机不移动灯。
- 距离/decay 使用现有 Web 与 Three 的逆幂衰减及四次距离窗；距离 0 表示无截断。聚光消费 angle/penumbra，使用一致的内外锥平滑权重。灯光仍走已有直接光 BRDF 与曝光。
- Frame ABI v3 保留 208/240 字节旧前缀，追加 16×64 字节灯数组，总 1264 字节。旧包保留旧灯光分支；新灯光变更复用完整候选渲染器事务。
- 局部投影阴影尚未接入：全局阴影开启且附加灯请求 castShadow 时阻断。主方向光的 cast/receiveShadow 已有真实差分覆盖。GI/HDR、面光和完整材质组合不在此次完成项。
