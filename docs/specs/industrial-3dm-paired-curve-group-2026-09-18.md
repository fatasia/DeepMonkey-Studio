# 3DM：四条曲面共边的共同分段重建

MechPartA 的 edge 69、71、79、81 复用 edge 93 的双侧证明与事务同步器，非共形边从 48 降为 44；41 面、7 条周期自缝保留，质量档仍为 `partial-geometry-preview`。

## 根因与预算

四条边的一侧是二次×一次有理曲面，另一侧是三次×二次曲面的精确 C3 边界。三次 C3 的两段对应二次曲线的一段，原算法因 knot 分段数不同拒绝。两侧源端点误差均小于 4e-15 mm，但中段曲线差约 0.00175 mm；不能直接复用 edge 93 的较小边界分配。

本片先验证所有目标 knot 都对应有序的源 knot，再提出缺失分段点；每个提出的点必须通过端点一致性检查，每个新区间仍以正权齐次控制网给出连续误差界。最近点搜索只提出候选，不作为证明。每条边得到 45 个已证明区间，连续界不超过 0.001981 mm。

只对取得上述双侧证书、且没有保存网格的四个曲面收紧离散预算：0.01 → 0.005 mm。已有网格不替换，其他面分配不变；既有共边处理在细化后照常执行。重建仍保留输入源 IR、源端点与内部旧点，整体副本通过邻边和自缝审计才提交。

同步阶段再次保守计入连续界。物理上限始终为 0.01 mm，源容差也未增加。精确 C3 锚侧最终界均小于 0.007515 mm。
