## 几何与连续界

只接受 identity 参数的正权有理三次×二次控制网，源内部结点重数必须等于对应次数。
据此直接提取原齐次 Bézier 子网，不拟合曲面、不改 knot、不另写求值器。
位置仍由既有原 NURBS 求值器取得；源参数映射、trim、孔洞、源边身份沿用现有实现。

对子网做平移和统一权重归一化，令齐次分子为 A、权重为 w，保证 `w >= 1`。
正权控制凸包给出 `|R| <= B`，R 为去除平移后的欧氏曲面。齐次导数控制网给出各
`|A_i|`、`|A_ij|`、`|w_i|`、`|w_ij|` 上界。商法则得到：

- `F_i = |A_i| + B*|w_i|`
- `M_ii = |A_ii| + B*|w_ii| + 2*F_i*|w_i|`
- `M_uv = |A_uv| + B*|w_uv| + F_u*|w_v| + F_v*|w_u|`

这些是整个子网的连续界，不是采样曲率估计。所有源 knot 并入 UV 网格，三角形
不能跨子网，因此允许源链在 knot 处只有 C0 连续，不把二阶导数误用于跨接缝的三角形。
网格复用含混合项的插值界 `(Muu*du²+2*Muv*du*dv+Mvv*dv²)/8`。
边界位置共用，结点处法线取对应右侧子网、末端取最后子网；所有三角均验证其三个顶点
源法线方向，不能保持方向时由共享边细分处理，超预算拒绝。

0.01 mm 源局部预算不变：10% trim、70% 插值，剩余计入 UV 合并与 Float32 量化。
控制网、细分网格、方向修复均有预算上限。未知参数化、非正权、非有限值、非法重数、
未知单位或无法满足精度时拒绝，不切换到商业转换器、缓存或替代几何。
