### 核查结论

**已有(不重建,零改动复用)**:
- GJK 窄相位 `convexDistance.ts`(逐位确定、含 Rapier 交叉验证先例);
- 时间扫掠机器 `runSweepCollision`(采样→球粗筛→窄相位→状态翻转二分→结构化报告);
- BVH 层 `analysis.ts`(`bvhCache` WeakMap + `closestPointsBetweenObjects`,静态校验在用);
- 人体语义层 `workcell-validation-plugin` 工效筛查、`spatialValidation` clearance/clearance-height(静态规则)。

**真实缺口(本切片补齐)**:
1. **生产入口**:扫掠只支持骨架 FK 轨迹(IKSkeleton+poseAt);人体过道/工具搬运/拆卸件抽取是
   **路径驱动刚体运动**,无入口;
2. **BVH 复用**:mesh→凸形状的确定性近似与缓存不存在;扫掠与 BVH 缓存的组合
   (同一场景 sweep 前后 BVH 不重建)无证据;`analysis.ts` 无对外 BVH 访问器;
3. **验收形态**:净空红线判定与人读报告不存在。

**边界(不碰)**:`scene.ts` 合同、`components/**`、T17 物理 runtime、WASM/GPU、`apps/api`;
N10 既有测试必须逐字保持绿。

## 3. 设计口径

### 3.1 路径驱动模式(缺口①)

```
输入:path(路标序列,时刻严格递增)+ movers(随节点 0)+ obstacles(静态)+ sampleCount
段内位置线性插值;航向最短弧插值(wrapToPi);区间外夹取端点。
framesAt(t) = [pathTransformAt(t)] → runSweepCollision 路径模式:
  采样 → 球粗筛(三角不等式下界剪枝)→ GJK 窄相位 → 状态翻转二分(1e-6 s)
输出(每对):minClearanceMetres / minClearanceAtSeconds / 最近点对 /
  firstCollision / collisionIntervals + requiredClearanceMetres + collided/violated
summary:worstClearanceMetres / worstPair / collidedPairCount / violatedPairCount / pass
meta:gjkQueries / sphereCulledSamples / refinementEvaluations(粗筛效率审计)
```

**航向轴 = +Z(引擎数学约定 z 轴向上)**,与 N10 机械臂绕 z 旋转、人体代理高度轴(原点在
脚底,z∈[0,h])同源。初版误用 +Y 会把站姿盒"放倒",测试当场捕获修复。

**保守性声明**:人体代理默认站姿盒(外廓尺寸精确,保守性由"外廓 ≥ 人体"选取保证);
胶囊代理返回**圆柱包络**(严格 ⊇ 胶囊),净空只低估不高估(安全方向),无角向欠近似。

### 3.2 网格→凸近似与 BVH 复用(缺口②)

- `sceneMeshConvexShape(geometry, {maxVertices=512})`:position 属性确定性等步长抽取
  (升序索引,无随机源);**凹体的顶点凸包 ⊇ 本体 → 保守**;WeakMap 按几何缓存
  (同 maxVertices 命中同实例,跨采样/跨运行只近似一次;参数变更显式重算不污染)。
- **BVH 复用证明(聚焦测试)**:同一场景内——静态复核建 BVH → 运行两次维护扫掠 →
  再次静态复核;`cachedGeometryBvh` 返回**同一 MeshBVH 实例**,静态距离逐位一致,
  凸近似缓存同实例。扫掠核心全程不构建任何 BVH。
- **凹体精确净空不在热路径**:在报告临界时刻(`minClearanceAtSeconds`/区间端点)用
  `analysis.ts closestPointsBetweenObjects`(BVH 缓存复用)按需复核。凸近似给保守下界,
  精确复核给真实值,两层互补、互不重建。

### 3.3 红线判定

`violated = minClearanceMetres < required − 1e-9`(恰好等于红线视为达标);
`collided = collisionIntervals 非空`;`pass = 全对无碰撞且无违规`。
逐体红线(`MaintenanceMoverSpec.requiredClearanceMetres`)覆盖场景默认值。

## 4. 验收与实测(2026-10-02,全部实跑)

**测试**:`maintenanceSweep.test.ts` **12/12 通过**;同族回归(N10 基线)
`convexDistance 39 + robotSweepCollision 9 + ikSkeleton 15 + ikPoseSearch 7 + ikRetarget 12 +
spatialValidation 18 + analysis 3` = **103/103 通过**;
本切片 4 文件 `tsc --noEmit` **零错误**(apps/web 全包现有 8 行错误均位于并行线路在途文件,
与本切片无关、未触碰)。

**解析对拍(节选)**:
- 盒代理过道:侧向净空 0.4(±1e-6),最小值时刻落在解析投影重叠窗口 [0.4083, 0.5917];
- 航向 45°:footprint 对角半宽 0.75·√2/2 → 净空 0.16967(±1e-5),红线 0.2 判违规;
- 工具球撞墙:碰撞区间 [0.3, 0.9](±1e-4 与解析一致),firstCollision 检出;
- 拆卸件抽取:BoxGeometry 顶点集净空 0.15(±1e-6);缓存复用(同实例)/参数变更重算(不同实例);
- 胶囊包络:圆柱半径 0.25 → 净空 0.25(±1e-6),报告人读输出含 [达标] 与结论行。

**Rapier 交叉验证(沿 N10 先例,升级为体-体投射)**:
球(r=0.1)vs 轴对齐盒(半边 0.3),扫掠最小净空 0.2 m;
在 minClearanceAtSeconds 位形沿"球心→盒面最近点"方向 `world.castShape`,
`time_of_impact` 与扫掠最小净空 **|Δ| < 1e-6**。

**Node 场景(证据 `test-output/e4-sweep-20261002/scenario-report.txt`)**:
- 场景一 人形代理过道(0.6×0.8×1.75,10 m/8 s,红线 0.5 m):双柱净空 0.6 m 达标;
  内伸机柜碰撞检出,区间 [3.3600s, 4.6400s],结论"未通过";
- 场景二 拆卸件(0.3³)上架抽取:侧置货架净空 0.25 m ≥ 0.2 m,结论"通过"。

**过程中修复的确定缺陷(同族排查)**:
1. 航向轴口径(+Y→+Z):站姿盒被旋入水平面,测试当场捕获;全文件仅 yawQuaternion 一处,同族干净;
2. Rapier `castShape` 返回字段为 `time_of_impact`(非 `toi`),初版读到 undefined 产生 NaN;
3. 恒定净空场景 `minClearanceAtSeconds` 断言:GJK 逐样本浮点噪声使首个最小值样本不保证 t=0,
   改为断言解析投影重叠窗口(诚实反映离散采样语义,不削弱数值对拍);
4. 同族排查:`frames[spec.nodeIndex]` 全部收敛到 `nodeFrameOf` 守卫(三处消费点),
   骨架模式行为逐字不变(原 9 测不改一行仍绿)。
