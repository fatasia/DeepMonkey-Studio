# 场景客户端资源依赖

场景打包从保存快照的显式引用选择应用、页面、模型、贴图和运行数据，再读取文件。空引用不回退全项目，选择与归属检查失败时不开始资源下载。

## 选择规则

| 范围 | 当前行为 |
| --- | --- |
| 应用与页面 | 以来源场景、场景视口和显式页面/场景动作关联应用，追踪启用动作与空间导航。保留活动分支、后代和必要祖先，不因祖先加入带入其他分支；无关页面、场景、交互和发布入口裁掉。 |
| 模型 | 使用 `getSceneModelAssetId` 区分实例与资源，兼容旧 modelId。保留隐藏对象声明的模型资源；资源必须属于当前项目、ready 且有几何。几何、属性、层级、PMI、检查记录和声明的 LOD 一并读取。 |
| 外观与脚本文件 | 按材质、环境、页面背景、静态媒体字段的完整 URL 或 assetId 匹配项目资源，保留所选材质的 maps。内嵌 data URI 保留；监控流地址仍是运行配置。脚本依赖读取已安装 assetUrl，核对 size 与 SHA-256 integrity。 |
| 运行数据 | 从保留场景绑定、页面组件及 application.data 的显式 ID 追踪 dataset、pipeline 与 connection。管线 source 指向的数据集一并选择；缺项、重复身份、跨项目及管线环拒绝。 |
| 下载与快照 | 相同 URL 只读取一次。带客户端目标的新发布保存所选依赖和内容寻址字节；首次交付与历史重试按版本读取，大小和 SHA-256 不符即失败。 |

关联应用中同 ID 的根场景使用本次保存快照。其余场景通过既有 `applicationToSceneSnapshotV1` 转换后收集资源，避免把 SceneDocument 当成含项目归属的 SceneSnapshot。

## 当前限制

无法静态枚举的启用脚本和语义模型数据绑定会阻止客户端打包；可停用相关内容或选择仅发布。只读 Worker 的导航权限通过现有 SDK 校验，具有数据访问权限的脚本仍需要数据依赖声明。跨应用动作没有 applicationId，目标不唯一时拒绝，不按碰巧相同的 ID 选取。

客户端发布只冻结 `/assets/projects/<当前项目>/...` 内静态对象，外部地址、签名地址和跨项目路径拒绝。诊断导出仍可在本次读取后脱敏，但不形成可重试的发布版本。模型内部未声明的外链仍需格式适配器处理，这批未扩展格式解码。

## 验证

纯选择器覆盖空引用、实例/资产身份、循环导航、无关空间分支、缺项与跨项目、URL 精确匹配、贴图和脚本哈希。真实 JSZip 导出测试核对应用/页面/模型/资源/runtime 内容，重复 URL 的读取次数，以及缺项、归属和哈希失败时不生成或下载 ZIP。

客户端包内容验证入口见[完整性协议](scene-client-package-integrity-2026-09-15.md)。

## 发布依赖与资源冻结

Web 与服务端复用 `studio-core` 的选择器。服务端先捕获字节，再在同一发布事务中复核草稿、原发布及依赖输入，保存独立 `scenePublicationDependencies`。记录绑定项目、场景、版本、时间和完整发布 SHA；Native 预检还提交实际资源 SHA，变化时停止发布。仅发布和旧历史保持原兼容路径，没有冻结记录的版本重试会明确失败。

资源按 `projects/<projectId>/publication-resources/sha256/<hash>` 保存。Local 使用完整临时文件的无覆盖硬链接；MinIO 上传后重新读取并校验。单资源上限 256 MiB，单次捕获上限 1 GiB。取消会关闭读流及 MinIO 子进程；上传接口没有取消能力时等待其结束再拒绝。已有损坏对象不会被静默覆盖。

元数据和资源通过 `/api/projects/:projectId/scenes/:sceneId/publications/:version/dependencies` 及其资源子路由读取，复用登录和项目权限。公开 `/assets` 拒绝冻结目录及点段、重复斜杠、Windows 短名等路径别名。匿名发布记录不附带依赖配置。

恢复历史版本复制其依赖并绑定新发布身份；撤回保留历史，场景删除及历史裁剪清理依赖记录。共享字节不在请求失败或单条历史删除时立即回收，当前没有自动 GC；项目删除会清理整个项目对象目录。

这一保证适用于历史客户端包。公开 browse 和云渲染仍有读取实时项目的路径，不属于本片冻结保证。PostgreSQL 仍沿用既有单写文档事务，没有新增多进程数据库 CAS。

## 本片验证证据

- 真实 JsonStore 重载、发布期间输入变化、历史恢复/裁剪、写入失败、路径归属、私有读取鉴权与 HTTP 断开均有集成回归。
- 真实 JSZip 验证历史打包不读取当前项目、应用或原 URL，prepared 与发布冻结输入不同拒绝交付。
- 真实 MinIO 源文件覆盖后仍可读原冻结字节，错误 SHA 和预取消被拒绝；证据 `test-output/d06-minio-live.json`，临时对象已清理。
