# Native 字体栅格化

`platform_text::TextRasterizer` 从本机字体生成真实 RGBA8 文字像素，供后续图表提示、图例和 Text IR 接线使用。

## 已完成

- 固定 `cosmic-text` 0.19.0，启用 `std`/`swash`，使用 Advanced shaping、字体回退与双向排版。API及版本依据：[官方 Buffer 文档](https://docs.rs/cosmic-text/0.19.0/cosmic_text/struct.Buffer.html)、[上游仓库](https://github.com/pop-os/cosmic-text)。
- 调用方提供文字、字体族、字号、行高、尺寸及颜色；输出 straight-alpha RGBA8、可见 glyph/line 数。透明像素与重叠字形按 alpha 合成，输出裁剪到指定视口。
- 宽高各限2048、文字UTF-8限16384字节、字体族限256字节；字号1–256、行高1–512，拒绝非有限数值及缺失字形。Swash图片缓存超过4096项时在下一次请求前清空；该阈值不是总内存硬上限。
- FontSystem跨请求保留，系统字体不打包、不分发。依赖许可见根目录 THIRD_PARTY_NOTICES.md，self_cell选择Apache-2.0。

Windows上的3项真实字体测试通过：Microsoft YaHei中文与拉丁文、阿拉伯文回退、组合字符、重复像素一致、调用方颜色保持、空文本透明、预算错误后恢复。检查依据为真实字体和像素内容，未加入字体文件夹具。Native all-target检查与repository gate通过。

## 图像通道接线与采样修复

RasterizedText::into_display_list现可生成实际ImageResource/Atlas/ImageCommand，稳定ID来自调用方身份，版本由调用方提供；检查RGBA长度/尺寸和最终DisplayList，输出颜色空间为rgba8unorm-srgb。仍是栅格图像适配，未冒充GlyphRun语义源。

真实中文GPU对照发现既有UV内缩半像素导致1:1模糊。现改为插值像素边缘UV、片元阶段限制在子区域像素中心范围；图集内部顶点从9个float扩为13个，绑定stride52，增加区域边界，不改变JSON合同。子区域放大仍无邻格串色。

验证：图像5/运行图集7/烘焙文字3/新图像层2共17通过，base64 RFC向量/全字节回读1通过；真实GPU中文逐像素alpha差≤1、单像素子区域放大不串色、既有烘焙文字失败回退3项通过。all-target检查与repository gate通过。

## 图表提示层

ChartIR窗口现将命中数据的系列、标签和值呈现在图内，位置在首次命中点旁，遇右/下边界翻转并限制在逻辑画布内。背景、文字、间距、圆角、字号来自base.css导出的设计令牌；宿主当前使用深色，呈现器支持注入两种主题。字符串去控制字符，每字段最多64字符，长内容仍可能在固定视口裁剪。

ChartRuntime源与几何帧使用Arc共享不可变快照，指针候选只复制交互状态；tooltip变化后先准备完整显示列表和GPU资源，再提交状态及恢复源，失败保留旧状态。重复命中同一数据点不重做字体栅格，移动到新数据点才重新呈现；离开或缩放清除提示。图内文字不参与几何命中。

## Axis tooltip聚合

TooltipContent从ChartIR源数据按共享xAxisId和相同X值聚合line/bar/scatter系列，结果保留seriesId、label、原始行和格式化值；隐藏系列排除，单项模式保留原行为，最多8项并返回omitted计数。数值比较使用JSON数字值相等，文本使用字符串相等；对数轴过滤非正或非有限Y值。渲染层以聚合条目行数决定视口高度，超限显示“另 N 项”。

聚合只在已确认tooltip状态后执行，绘制不改变命中索引；当前轴提示仍依赖命中的一个数据点作为X锚点，线段中部最近X和跨数据集时间轴对齐尚未实现。Tooltip文字目前每次候选重新栅格，尚无跨帧文本缓存。
