## 已完成

- 新增 `record-form` 画布组件，复用已有 data-widget 文档、资源目录、检查器和发布保存链路；固定记录编号与已保存数据集绑定，未增加后端写回接口或第二套状态机。
- 作者浏览态显式传递 userId/canWrite、当前项目数据集及确定写入后的指标刷新回调。复用 DatasetWritebackPanel/session/cache 的校验、确认、409 比较、未知结果核对和刷新失败只读重试。
- 固定记录只自动读取，不自动提交；草稿按用户/项目/数据集/记录隔离。退出预览或刷新后恢复草稿时不自动重新读取覆盖修改，必须主动核对。
- 匿名页不挂载表单会话；即使脚本提供 runtime value，填报类型仍强制只读占位，发布文档不能授予写权限。viewer 仍受 UI 和既有后端权限约束。
- 表单内容在组件内滚动；不兼容的示例/直连/管道/语义绑定不能直接切换成填报，悬浮说明原因且不清除原绑定。资源缩略图新增输入框与提交键的真实线框，不使用通用 Shapes 占位。
