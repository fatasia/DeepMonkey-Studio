# 行业模板可读性修补 · 2026-09-08

## 根因与限定实现

先复核 r41 行业门禁及 r42 实际 PDF：页面存在、图表有像素并不代表信息可读。1920 设计画布的原表头 8px、标签 9–10px 被等比缩至 980 后只有约 4–5px；原模板没有显式设计字号，运行器也没有把饼图 `showLegend` 配置消费进去。作者浏览态默认展开参数查询，遮挡首屏 KPI。

本批沿用 FVS 的设计画布等比适配、标题 / 单位和数值层级，以及西门子的克制信息密度。不改客户保存的参数，不给全局文字加 `!important`。

- 新模板写入 24px 设计字号、32px 页面标题；头区 / 筛选区增到 88px，KPI 高度 132px；已有客户节点没有字号时沿用原路径。
- 显式字号通过独立局部样式驱动画布标签、表格、单位、筛选和数值层级；工作台壳层不受影响。
- 新增独立纯图表配置构造器，支持当前行业包使用的柱、折、面积、组合与饼图；读取既有字号、堆叠、次轴、图例与数据标签设置，不改原聚合数据。标题与单位留在图表上方，饼图显示真实分类图例及百分比。
- 新图表系列使用既有品牌 / 语义令牌；文字与背景读取实际作品配置，保留已保存深色画布在浅色工作台中的外观。
- 参数查询默认收起，通过项目控制中的“参数”按钮可键盘展开；不增加说明墙或徽章。
