## 实施范围

当前二维页普通数据集组件：生成流式草案 → 合同/实际项目数据集字段校验 → 增改删差异 → 用户确认后一条工作区命令 → 原有撤销/重做、保存、刷新 → 同页第二轮修改。模型不能修改其他页面、场景、脚本、直连凭据、样本行、语义组件或锁定节点。确认时重新读取字段目录，当前项目/应用/页面/修订/页面内容基线变化则拒绝旧草案。取消/关闭后迟到结果不落草稿；只读身份不提供生成入口。

公共命令独立验证 JSON/操作类型/节点/布局，不以 TypeScript 或前端校验替代运行时验证；既有数据 key 不改，已知跨页参数、flow source、脚本 target 的显式引用阻止删除。任意脚本源码内动态查找不属于静态引用分析范围。
