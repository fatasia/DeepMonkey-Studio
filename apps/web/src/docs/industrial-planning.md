# 工厂规划、PPR 与机器人控制验证

“智能运营”把工厂规划、工艺规划和机器人控制验证拆成可独立完成的专业任务。每次运行都应保留输入、引擎、结果和证据，不把起步参数或快速初筛冒充最终工程结论。

## 选择工厂规划任务

从项目工作台进入“智能运营”，选择“工厂规划”。页面提供三种任务：

- “物流快速估算”适合用少量参数判断吞吐、利用率和明显瓶颈。
- “流程仿真”使用 Plant Lite 离散事件仿真，适合验证节点、连接、缓冲、资源、班次和波动。
- “工艺规划”使用 PPR/BOP 建立产品、工序和资源，再生成流程仿真草稿。

先按交付问题选择一种任务，不必为了运行流程仿真先完成全部高级参数。

## 建立 PPR 工艺计划

在“工艺规划”点击“打开工作台”，按三个步骤操作：

1. “产品结构”：建立产品、部件和层级，按需设置适用变体。
2. “工序安排”：填写标准工时、前置关系、物料角色，并为关键工序补电子作业指导书（EWI）、安全注意和质量控制点。
3. “资源配置”：建立工位、设备、机器人或人员，设置并行能力并分配到工序。

右侧持续显示关键路径、排程、资源冲突、产线平衡和质量覆盖。处理阻断项后点击“保存为新版本”；需要验证产能时点击“生成仿真草稿”。该动作只转换已确认的 PPR 输入，不会自动运行仿真。

## 运行 Plant 流程仿真

在“流程仿真”先检查 Study 名称、seed、重复次数、预热与统计窗口，再按实际范围配置：

- 来源、工位、缓冲、搬运和成品节点及其连接。
- 加工和搬运时间分布、队列容量、并行能力、班次、设备和人员资源。
- 可选的订单、产品混流与换型、良率、故障修复、能耗、电价与碳排参数。

点击“运行流程仿真”。结果先给出瓶颈与下一步，再提供物流轨迹回放、统计窗口、吞吐 / WIP / 交付周期的 95% 区间、验收目标和方案比较。需要优化时，从“改进实验”运行缓冲、瓶颈或可靠性候选；需要现场校核时选择数据中心的数据集并完成字段映射。

导出的工程证据包包含可复现输入、统计区间、谱系和轨迹完整性。轨迹被截断只影响可视化明细，不应改写统计结果；旧记录缺少证据时应重新运行。

## 验证机器人与控制逻辑

选择“机器人与控制验证”：

1. 选择场景和已启用关节链的机器人，点击“检查任务”。
2. 核对目标、TCP、负载、速度、动作时间、目标节拍和安全间隙，再点击“生成任务并验证”。
3. 查看可达包络、关节限位、AABB 碰撞初筛、轨迹与节拍预算；修正阻断项，或“保存快速初筛”。
4. 点击“验证控制逻辑”，运行启动、故障联锁、人工复位和结果断言预设。
5. 在结果页定位失败对象、拖动回放时间并导出证据；需要修改时返回控制用例或重新检查任务。

快速验证不会生成控制器程序，也不会下发设备。它不替代完整 IK、网格级连续碰撞或真实控制器时序校核；这些边界会随证据一起显示。

准备数据的步骤见[数据中心](/docs/data-pipeline)，交付前按[预览、体检与发布](/docs/server-publish)完成最终检查。
