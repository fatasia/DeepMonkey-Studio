# AGV 实时与仿真运动切换

AGV 扩展提供轻量的运行模式切换、节拍统计和路径回放。它是可选插件：插件未安装、被禁用或运行失败时，二维编辑、三维编辑、数据接入、保存和发布仍应正常工作。

## 准备路径和车辆

在三维场景中为 AGV 模型设置稳定对象 ID，并在拓扑编辑器创建站点和有向路径。路径只描述站点连接、距离和限速，不在主应用中引入完整离散事件仿真内核。

## 绑定实时数据

在数据中心接入 AGV 调度系统的 HTTP 或 WebSocket 数据，将车辆 ID、位置、朝向、速度、任务和时间戳映射为标准字段。实时模式按时间戳插值，短暂断流时保持最后状态并显示数据陈旧提示。

```json
{
  "vehicleId": "agv-01",
  "position": { "x": 12.4, "y": 0, "z": 8.1 },
  "heading": 1.57,
  "speed": 1.2,
  "timestamp": 1787625600000
}
```

## 运行仿真模式

切换到仿真模式后，选择起点、终点、车辆数量、目标速度和装卸时间。运行控制器提供开始、暂停、单步、倍速和复位。基础结果包括吞吐量、平均节拍、等待时间、利用率和阻塞时间。

## 安全切换模式

1. 暂停当前运行模式。
2. 保存车辆当前位置和任务快照。
3. 选择实时或仿真数据源。
4. 校验车辆 ID 和路径版本后恢复运行。

模式切换不会覆盖实时数据，也不会把仿真事件写回生产调度系统。若校验失败，继续显示最后一个稳定状态，并允许用户返回三维编辑器修复路径。

复杂车辆表现可以通过[行为脚本](/docs/behavior-script#响应数据和交互)扩展；数据接入见[连接和验证数据源](/docs/data-pipeline#连接和验证数据源)，完整 Plant 流程见[工厂规划](/docs/industrial-planning#运行-plant-流程仿真)。
