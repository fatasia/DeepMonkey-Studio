# 连接数据、处理逻辑并发布接口

数据中心按“接入数据 → 处理逻辑 → 发布接口”组织任务。先证明连接与字段可用，再编排逻辑，最后把同一条流水线提供给 2D、3D、脚本或外部系统。

## 连接和验证数据源

1. 从项目工作台点击“数据”，进入“接入数据”。
2. 点击“新建连接”，选择数据库、HTTP、文件、消息流或现场协议，填写连接参数并保存。
3. 在连接卡片点击“测试”。只有连接成功后，才继续定义数据集。
4. 选择连接，点击数据集区域的“新建”，填写查询、数据路径、字段和刷新频率。
5. 保存数据集后点击“运行查询”，检查行数、耗时和字段；看到“字段已同步”才进入下一步。

连接运行监控会显示延迟、读取、写入、重连和连续失败。标记为“需要安装连接器”的类型在连接器就绪前不能创建或预览数据集，不应使用模拟结果代替。

## 编排处理逻辑

点击“用这些字段编排”或切换到“处理逻辑”：

1. 创建流水线并选择来源数据集。
2. 从左侧加入过滤、计算、脚本、排序或输出节点。
3. 选择节点，在下方检查器填写参数；画布上的诊断会指出断链、字段或配置错误。
4. 先“保存”，再“运行”。“运行成功”同时证明节点顺序、字段合同和输出样本可执行。
5. 场景只绑定已保存的数据集或流水线；临时草稿不会成为可靠的数据产品。

复杂设备接入可进入“高级接入”，但数据库、HTTP、WebSocket、MQTT、OPC UA、Modbus 和 Kafka 等核心连接仍由平台数据中心管理。

## 发布和测试接口

流水线完整运行成功后点击“发布接口”：

1. 选择 REST 或 WebSocket，并绑定已保存的流水线。
2. 设置接口名称、路径、启用状态、认证和运行预算。
3. 点击“测试”，先验证响应、诊断和样本。
4. 点击“保存”后再复制运行地址和 API Key 使用说明。

接口失败时回到流水线运行一次；流水线失败时回到数据集重新运行查询；数据集失败时回到连接卡片检查连接监控。按这条逆向链路排查，避免在场景属性里反复改绑定。

## 绑定到场景或拓扑

二维实例在右侧“数据”中选择数据集或流水线；三维对象在“数据绑定”中选择唯一来源、字段、目标属性和更新规则。拓扑节点也可绑定数据集或流水线的运行字段。

直接 HTTP / WebSocket 仍可作为降级路径，但可复用、可追溯的数据应优先进入数据中心。继续阅读[拓扑编辑与数据绑定](/docs/topology-resources#绑定运行数据)或[行为脚本](/docs/behavior-script#响应数据和交互)。
