# 从项目到首个可发布场景

一条完整交付路径是“项目 → 资源 → 二维 / 三维 → 数据与交互 → 预览 → 体检 → 发布”。二维页面、三维场景和行为脚本属于同一个应用，切换工作区会保留上下文。

## 创建项目与场景

1. 在项目工作台左上角选择当前项目；新建、重命名和删除项目位于旁边的项目管理菜单。
2. 在“项目场景”使用搜索、状态和排序定位内容，或点击“新建场景”。
3. 输入场景名称并点击“创建并进入”。新应用从空白二维页面开始。
4. 需要复用模型、媒体或材质时，先到[资源（项目资源页）](/docs/resource-workflow#认识两个资源范围)确认资源状态。

项目切换会同时切换场景、资源、数据和工业任务范围。操作前先核对顶部当前项目，避免把内容建到错误项目。

## 编辑二维与三维

二维工作区从左侧“资源”点击或拖入指标、图表、媒体和三维场景实例。选中实例后右侧显示内容、样式、数据和交互；点击画布空白处才显示页面名称、逻辑分辨率、适配方式和背景。

逻辑分辨率决定发布画布坐标系，不等于显卡输出分辨率。首次进入超宽页面时使用“聚焦可见组件”，需要检查整页边界时使用“完整显示看板”。

对三维场景实例双击，或点击右侧“进入三维编辑”。三维左侧场景目录支持 `Ctrl` / `Command` 多选、编组和拖动层级，右键完成就地管理。左右辅助面板都可收起，画布保持主操作焦点。

顶部“二维 / 三维 / 脚本”工作区切换保留当前应用名称。脚本编辑器可隐藏、悬浮或分屏，分屏时可拖动调整代码与场景预览宽度。

## 接入数据与交互

可复用数据先在数据中心完成连接测试、数据集预览和逻辑运行，再回到二维或三维绑定。组件和对象只选择一个数据来源，避免数据集、流水线与直连同时生效。

常用点击、显示隐藏、聚焦、页面或场景跳转优先使用交互面板；只有图形化动作不能覆盖时再创建行为脚本。完整步骤见[数据中心](/docs/data-pipeline)和[行为脚本](/docs/behavior-script)。

## 保存并验证

保存前确认顶部上下文是当前应用。预览至少验证一次首屏、关键数据、2D / 3D 联动、脚本、媒体和窗口缩放。

回到项目场景页后，场景卡可直接预览、编辑、发布、复制链接和重命名。发布前展开“查看流程”进入体检；阻断项修复后再发布。详见[预览、体检与发布](/docs/server-publish#交付前自检)。

意外关闭或刷新后出现本地草稿时，不要直接丢弃；按[恢复未保存修改](/docs/troubleshooting#恢复未保存修改)处理。
