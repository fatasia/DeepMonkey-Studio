# 创建 2D 大屏并绑定 3D 场景

这篇指南用一条完整路径说明如何创建二维页面、设置大屏分辨率，并把图表与三维场景绑定起来。二维与三维属于同一个应用，切换编辑器不会丢失页面上下文。

## 创建应用和大屏页面

1. 在主页选择项目，点击“新建应用”。
2. 进入二维编辑器后新建页面，输入页面名称。
3. 在页面设置中选择 `1920 × 1080`、`3840 × 1080`、`3840 × 2160` 或自定义逻辑分辨率。
4. 选择适配方式：等比包含、等比铺满、拉伸或固定尺寸。

> 逻辑分辨率决定发布画布的坐标系，不等于浏览器或显卡的实际渲染分辨率。先按目标大屏比例设计，再使用预览检查裁切和溢出。

## 添加组件并绑定数据

从组件库拖入指标卡、折线图或表格。选中组件后，在右侧“数据”面板选择数据产品和输出字段。需要公式或转换逻辑时，先到数据中心创建计算字段，再回到页面完成绑定。

图片、普通视频和实时监控的资源上传、流接入与发布检查见[看板媒体指南](/docs/media-widgets#添加实时监控)。

## 绑定三维场景

1. 添加“三维场景”组件，或选中需要联动三维的二维组件。
2. 在属性面板选择当前应用中的场景。
3. 选择默认摄像机视角，并配置点击、双击或数据变化触发器。
4. 点击“进入三维编辑”调整模型、摄像机和交互；返回时会恢复二维画布的缩放、滚动位置和选中对象。

二维组件可以发送 `select`、`filter` 和 `navigate` 事件，三维场景可以回传对象选择和设备状态。两侧通过应用事件总线联动，不复制数据源。

## 预览和发布检查

- 在目标比例下检查文字、图表、三维窗口和安全边距。
- 使用预览模式验证二维点击能定位三维对象，三维选择能筛选二维组件。
- 确认页面没有越界组件和失效数据绑定。
- 发布前保存应用版本，并记录目标服务器。

下一步可阅读[配置服务器并发布](/docs/server-publish#发布应用)，或者用[行为脚本](/docs/behavior-script#创建行为脚本)扩展复杂联动。
