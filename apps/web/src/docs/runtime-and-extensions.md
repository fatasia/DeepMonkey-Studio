# 选择运行方式与扩展能力

平台把编辑、运行和交付分开：作者在 Web 或桌面工作台编辑，使用者只打开已发布内容。开始项目前先选运行方式，避免把本地草稿、在线项目和发布版本混为一谈。

## 选择工作方式

- Web 工作台连接当前服务器，适合使用项目数据、AI、工业任务、团队账号和在线发布。
- 桌面“本地工作台”不填写服务器地址也能创建、编辑和保存 2D、3D 与脚本，并可导出项目包；需要在线数据、AI 或发布时再切换服务器模式。
- 发布浏览页只运行已冻结版本。可分别选择 WebGL、WebGPU 优先、云渲染或只读 Windows 场景客户端，不向浏览用户暴露编辑能力。

桌面端显示“上次服务器不可用”时可以继续进入本地工作台。切换到另一台服务器前先保存或导出本地项目；服务器地址改变不会自动迁移项目数据。

## 使用基础能力

核心 Web 编辑、2D / 3D、脚本、数据编排和本地场景浏览由仓库锁定的运行时提供。项目按根目录许可证公开源码，第三方组件遵循各自许可证。开发人员可在仓库根目录启动：

```bash
pnpm install --frozen-lockfile
pnpm studio start web
```

需要同时启动桌面客户端时使用 `pnpm studio start client`。启动、关闭、重启、状态检查与生产部署都通过同一个 `pnpm studio` 入口完成。核心开发要求 Node.js 24 与 pnpm 11；普通安装包用户不需要安装 Node.js 或 Python。

产品菜单中的“开源项目致谢”用于查看直接依赖和许可证；精确版本及分发说明以发行包内 `THIRD_PARTY_NOTICES.md` 为准。新增依赖前应重新运行依赖与许可证审计，不能只根据项目首页判断可商用性。

## 接入商业扩展

Unity 资源、高精度 CAD 转换、厂商控制器或专用求解器通过可选适配器进入平台。适配器只返回统一资源、场景对象或 Study 证据，不建立第二套项目、权限和发布体系。

使用前在系统能力页核对三个状态：适配器已配置、运行探针通过、目标格式或任务已用真实样本验证。只有声明格式但没有可用 Provider 时，任务会停留在等待状态；不要把文件扩展名识别当成模型可用。

Revit 导出依赖安装了匹配版本 Revit 的 Windows 主机；DWG 开源链需要单独安装 LibreDWG；其他专业格式按部署启用的 Provider 为准。未启用这些扩展不会影响 GLB、glTF、IFC、OBJ、FBX、STEP、DXF 与 OpenUSD 已有路径。
