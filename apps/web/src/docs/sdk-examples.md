# SDK 可运行样例

从小段可编辑代码开始，了解 `studio` 在场景里的运行方式。下面的样例直接使用当前 Worker 行为脚本 API 1.0，不需要安装项目依赖。

## 选择、修改和运行

先打开项目的二维或三维编辑器，再从文档新增样例。确认目标项目后，工作台会创建独立脚本文件；同名文件自动编号。新增本身不会运行或发布；保存遵循编辑器当前的自动保存设置。

已有文件和未保存修改会由编辑器的草稿保护保留；无名称草稿需要先命名。进入编辑器后可修改源码、点“运行”查看日志，也可停止试运行，再按需保存脚本。样例默认启用，保存并发布后会遵循应用原有的自动生命周期。

## 执行上下文与可用 API

样例挂载到整个场景，在 Worker 中执行。`studio` 由运行时提供，生命周期函数通过 `ctx` 取得场景标识、数据和事件上下文。代码内的 API 清单与所需声明会随样例一起显示。

生命周期样例使用 `studio.version` 和 `studio.log`；变量样例使用 `studio.getData` 并声明 `data.read`；事件样例使用 `ctx.event`。三个样例只读取上下文和输出日志，不写应用变量、不改对象、不访问网络。

Worker 不提供 DOM、`window`、`document` 或 `studio.raw`。主线程交互脚本的页面导航、场景枚举和原始 Three.js 对象不适用于这里；完整边界见 [`studio` 应用 API 手册](/docs/studio-api)。

## 场景脚本与私有 SDK 包

这里的 `studio` 是项目脚本运行时注入的 API。仓库中的 `contracts`、`scene-sdk` 和 `server-sdk` 是另行验证的私有协议、调度与 HTTP 客户端包，不是可直接嵌入任意网站的完整 Viewer。样例新增不安装或发布这些包。

项目脚本依赖的安装方式见[编写和运行行为脚本](/docs/behavior-script#安装并离线使用依赖)。
