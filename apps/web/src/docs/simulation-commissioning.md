# 仿真与虚拟调试

“智能运营”统一承载快速估算、Plant 流程仿真、PPR 工艺规划、机器人工位检查和虚拟调试。每个任务都应形成可复现 Study：输入版本、运行配置、结果、限制和证据一起保存。

## 选择正确的验证深度

- 公式估算用于几分钟内比较吞吐和明显瓶颈，不输出离散事件置信区间。
- Plant Lite 用于队列、缓冲、班次、故障和随机波动下的流程验证。
- 机器人工位快速检查用于可达包络、关节限位、必要碰撞对和节拍预算。
- 虚拟调试用于控制信号映射、故障与复位顺序、断言和回放。

快速结果用于筛选方案，不应冒充控制器级时序、完整 OLP、网格级连续碰撞或现场安全验收。

## 进入虚拟调试

在“智能运营”选择“机器人与控制验证”，然后：

1. 选择三维场景；若场景包含已启用关节链的机器人，可继续选择目标机器人。
2. 点击“检查任务”，先完成机器人或通用工位快速检查并处理阻断项。
3. 进入“控制验证”，至少添加一条信号映射，将输入、输出或内部信号关联到稳定对象。
4. 设置运行时长、步长、速度给定、故障注入、人工复位和验收断言。
5. 运行单个场景，或运行内置黄金测试矩阵覆盖启动、联锁、故障、复位和结果断言。

场景没有设备时先回三维编辑器创建或导入对象；没有信号映射时运行按钮会阻止提交，而不会生成演示数据。

## 回放与定位问题

结果页先看通过、失败和未执行，再使用时间轴定位第一个失败时刻。证据会保留信号变化、断言、目标对象和 trace；点击目标可返回三维视口定位设备。

修改映射或用例后重新运行会形成新结果。导出证据时使用当前运行的输入与结果，不手工拼接旧截图。黄金矩阵中任一用例失败时，应先检查互锁和复位顺序，再判断是否需要更高精度求解器。

## 与 Plant、PPR 和脚本联动

PPR 可把已确认的工序、前置关系和资源分配生成 Plant 草稿；Plant 结果用于识别工位和缓冲问题；机器人工位检查与虚拟调试验证关键设备和控制顺序。三者通过场景对象 ID 和 Study 版本关联，不复制场景。

行为脚本可驱动演示动画和数据响应，但不应替代验证断言。完整 Plant、PPR 与机器人流程见[工厂规划、PPR 与机器人控制验证](/docs/industrial-planning)，数据准备见[数据中心](/docs/data-pipeline)。
