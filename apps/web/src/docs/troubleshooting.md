# 交付自检与故障恢复

出现异常时先保护当前修改，再沿“项目 → 资源 → 数据 → 编辑器 → 预览 → 发布”逐层定位。不要通过反复刷新或重新创建项目掩盖真正的断链。

## 恢复未保存修改

编辑器发现本地草稿时会显示“发现未完成的本地修改”：

- 服务器没有更新时，选择“恢复到当前页”，核对后重新保存。
- 服务器版本更新时，先“导出副本”，再恢复查看，避免覆盖对方版本。
- 暂时无法判断时选“稍后处理”；只有确认副本无价值时才“丢弃副本”。

Plant 流程仿真的未运行草稿按项目保存在本地。重新进入“工厂规划”后先核对恢复的 Study、节点和运行条件，再执行仿真。

## 资源或画布为空

- 资源搜索无结果：清空搜索词、分类和范围，确认正在浏览“公共资源”还是“项目资源”。
- 二维画布看不到实例：使用“聚焦可见组件”；检查图层是否隐藏、锁定或越出页面边界。
- 三维视口看不到模型：在场景目录确认对象可见，再执行适应全部；模型状态不是“可使用”时回到项目资源查看转换诊断。
- 材质不符合预期：先点击“重置颜色调整”；确认修改的是模型还是内部构件，避免实例覆盖叠加。

## 数据、脚本或拓扑没有运行

- 数据：连接“测试” → 数据集“运行查询” → 流水线“运行” → 接口“测试”，从最早失败的一步修复。
- 场景绑定：确认只选择了一个来源，字段仍存在，目标对象没有删除；重新预览一次数据后保存。
- 脚本：先“应用修改并运行”，查看诊断和运行日志；对象 ID、数据键、能力或权限失效时使用引用定位和“一键补齐声明”。
- 拓扑：确认当前项目和拓扑正确、节点或连线未被筛选，保存状态完成；运行值为空时检查绑定字段与数据集 / 流水线。

## 发布被阻止或发布后异常

打开项目的“查看流程”并进入发布体检。阻断项必须处理，常见原因包括：

- 模型仍在转换、场景模型与项目资源断链、Unity 版本不存在。
- 数据集、流水线、媒体资源、三维对象、页面或相机视角引用失效。
- 交互动作没有可执行内容，或外部链接不是有效 HTTPS 地址。
- 发布端性能不足时先查看运行诊断；只有交付者允许时才启用极速模式。

发布后仍可编辑草稿。需要回到稳定发布内容时，在场景卡“更多”中打开“版本历史”并恢复目标版本；恢复会形成新的发布记录，历史不会被抹去。

## 工业结果缺少证据

- Plant 旧记录没有轨迹或节点统计：用当前工况重新运行，不根据空白图表猜测结果。
- PPR 无法生成仿真草稿：补产品、正数目标节拍、工序关系和必要资源，再处理右侧阻断项。
- 机器人无法生成任务：在三维场景启用机器人关节链，并配置有效目标对象；缺少包围盒、TCP、负载或关节位姿会明确保留为“缺失证据”。
- 控制逻辑无法运行：先配置至少一条 I/O 映射，再运行预设或展开自定义用例。

恢复完成后重新执行[预览、体检与发布](/docs/server-publish#交付前自检)，确保修复进入新的可复现版本。
