# 交付自检与故障恢复

出现异常时先保护当前修改，再沿“项目 → 资源 → 数据 → 编辑器 → 预览 → 发布”逐层定位。不要靠反复刷新或重新创建项目来掩盖真正的断链点。

## 恢复未保存修改

编辑器发现本地草稿时会弹出“恢复未保存修改”，并说明是“本地修改尚未保存”还是“服务器已有更新版本”，后者会写明本地基于哪个版本、服务器现在是哪个版本。

- 服务器没有更新时，选“恢复到当前页”，核对内容后重新保存。恢复后自动保存会暂停，保存要手动点。
- 服务器版本更新时，先点“导出副本”留一份，再恢复查看，避免覆盖别人的修改。
- 暂时无法判断时选“稍后处理”：保留本地副本，先用服务器版本进入编辑器。
- 只有确认副本没有价值时才点“丢弃副本”。

Plant 流程仿真中还没运行的草稿按项目保存在本地。重新进入“工厂规划”后，先核对恢复的 Study、节点和运行条件，再执行仿真。

## 资源或画布为空

- 资源搜索没有结果：清空搜索词、分类和范围，确认当前浏览的是“公共资源”还是“项目资源”。
- 二维画布里看不到实例：点画布工具里的“聚焦页面中的可见组件”；再检查图层是否被隐藏、锁定或移出了页面边界。
- 三维视口里看不到模型：先在场景目录确认对象可见，再执行适应全部；模型状态不是“可使用”时，回项目资源看转换诊断，“待转换器”表示这种格式或版本还没有可用的解析器：内置解析没有覆盖，或者部署方自备的转换器没有配置，见[模型导入与格式选择](/docs/model-import#选择输入格式)。
- 材质不符合预期：先点“重置颜色调整”，确认改的是模型本身还是内部构件，避免实例覆盖层层叠加。

## 资产修订和删除提示

- 模型卡片出现“已陈旧”和“资产修订陈旧”：说明项目资源里有比场景引用更新的修订。核对新修订之后点“更新到最新版本”，或者点“保持当前”忽略这次提醒。更新失败时点“重试更新”，错误原因会留在卡片上。详见[资产有新修订时](/docs/resource-workflow#资产有新修订时)。
- 删除确认框写着“仍被 N 处引用”：先看“影响范围”里列出的场景和字段，改用其他资源或确认可以断开后再删除，删除后用发布体检复查。

## 数据、脚本或拓扑没有运行

- 数据：连接“测试” → 数据集“运行查询” → 流水线“运行” → 接口“测试”，从最早失败的一步开始修。
- 场景绑定：确认只选了一个来源，字段还在，目标对象没有被删除；重新预览一次数据后再保存。
- 脚本：先点“试运行”（`Ctrl+Enter` 会先应用当前草稿再运行），查看诊断和运行日志；对象 ID、数据键、能力或权限失效时，使用引用定位和“一键补齐声明”。
- 拓扑：确认当前项目和拓扑正确、节点或连线没有被筛选掉，并且已经保存；运行值为空时，检查绑定的字段和数据集 / 流水线。

## 三维效果与出图

- 打开模型动画的“根运动”后，模型被带到了别处：点“复位根运动位置”。已经出现“含根运动位移，保存前建议复位”的提示时，保存前先复位，否则漂移后的位置会被一起存下。
- “根运动”开关是灰色的：悬停看原因，通常是模型被锁定、没有动画，或当前片段没有根骨骼的平移轨道。
- 火焰图层比预期稀疏：看面板里的“场景预算”。超出场景粒子预算时，实际绘制数量会按比例降低，调低其他火焰的密度或粒子上限即可。
- 开了体积雾却看不到效果：体积雾只在 Deep WebGPU 下完整生效。Deep Native 使用受限的积分，Three WebView 发布时降级为普通的作者雾；先在“更多 → 渲染引擎”确认当前后端。
- “物理光照出图”里“导出 HDR”点不了：这个按钮要等到“已收敛”才可用。状态是“尚未收敛 · 可保存预览”时，可以先“保存预览”，或者提高样本上限继续积累。积累中改动了场景，会提示“场景已修改 · 积累已清空”，需要重新开始。

## AI 助手没有回答或结果不对

- 提示“本次请求未完成”：没有任何变更被写入，原问题已经保留。依次试“重试原问题”“换备用模型重试”；问的是数据相关的问题，再试“改用受控问数”。
- 回答里缺了项目信息：展开“本次上下文”，看是哪个来源读取失败。失败的来源本次回答不会使用，先修好这个来源再问。
- 回答没有提到较早的内容：对话很长时只有最近几轮会发给模型，面板会提示被省略的轮数，把关键前提在新问题里重新写一遍。
- 切换会话后看不到刚才的对话：用标题下方的会话下拉，必要时选“更多会话…”加载更早的记录。出现“另一个窗口更新了此会话”时点“载入最新”。
- “执行任务”里“运行”按钮不可用：需要先选择项目，并至少选中一项能力；展开“能力、风险与证据预览”核对。
- 助手要求“执行前需要你确认”：这是写入或控制类操作的正常门禁，核对作用范围和精确参数后再点“确认并继续”，没有把握就点“取消任务”。

## 发布被阻止或发布后异常

在项目场景页点“展开开发流程”，进入“智能发布体检”和“交付校验”。阻断项必须处理，常见原因有：

- 模型仍在转换、场景里的模型和项目资源断链，或者 Unity 版本不存在。
- 数据集、流水线、媒体资源、三维对象、页面或相机视角的引用失效。
- 交互动作没有可执行的内容，或者外部链接不是有效的 HTTPS 地址。
- 发布端性能不足时，先看运行诊断；只有交付者允许时才使用“极速模式”。

下载 Windows 客户端失败时：Three WebView 提示启动器不可用，说明管理员还没有配置通用启动器；提示没有权限，说明账号是只读角色或没有该项目的访问权限。已经发布的网页版本不受影响，修好后可以重试打包。

发布后仍然可以继续编辑草稿。需要回到稳定的发布内容时，点场景卡上的“版本历史”，恢复目标版本；恢复会形成新的发布记录，历史不会被抹掉。

## 工业结果缺少证据

- Plant 的旧记录没有轨迹或节点统计：用当前工况重新运行，不要根据空白图表猜结果。
- PPR 无法生成仿真草稿：补齐产品、正数的目标节拍、工序关系和必要资源，再处理右侧的阻断项。
- 机器人无法生成任务：在三维场景里启用机器人关节链并配置有效的目标对象；缺少包围盒、TCP、负载或关节位姿的，会明确保留为“缺失证据”。
- 控制逻辑无法运行：先配置至少一条 I/O 映射，再运行预设或展开自定义用例。

恢复完成后重新走一遍[预览、体检与发布](/docs/server-publish#交付前自检)，让修复进入新的、可以复现的版本。
