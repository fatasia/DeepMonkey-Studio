# 拓扑编辑与数据绑定

拓扑是项目内可复用的设备与关系图，可独立编辑，也可插入二维页面。拓扑文档保存节点、连接、点位、阈值、扩展属性和展示配置；运行值来自数据适配器。

## 创建拓扑

1. 在项目工作台进入“拓扑”，点击“新建拓扑”。
2. 从左侧加入设备节点，选择创建连线后依次点击起点和终点。
3. 拖动节点整理位置，使用缩放或自动布局检查整体结构。
4. 在右侧“属性”配置名称、图标、状态、阈值、连接语义和自定义扩展属性。
5. 保存后刷新，确认节点、连线和视图恢复。

`Shift` / `Ctrl` 支持多选，`Ctrl+D` 复制。2D 与 2.5D 只改变投影展示，不改写工程坐标。

## 绑定运行数据

选择节点，在右侧数据区域选择已保存的数据集或流水线，并配置字段、阈值和状态映射。没有数据产品时，先按[数据中心](/docs/data-pipeline#连接和验证数据源)完成连接、数据集和运行验证。

拓扑运行时只读取绑定输出；节点和连线结构不会随实时值被覆盖。字段被删除或来源断开时，应显示缺失状态而不是保留伪造的在线值。

## 插入二维页面

保存拓扑后点击“插入看板”，它会作为二维实例加入当前应用首页。进入二维编辑器后可调整位置、尺寸、层级、样式和交互；拓扑源文档仍在项目“拓扑”中维护。

发布前在预览中检查节点状态、告警、缩放和与三维对象的联动。拓扑为空时先核对当前项目和拓扑，再确认保存状态与筛选；运行值为空时沿数据集、流水线、字段顺序排查。

资源的浏览、插入和引用治理见[资源工作流](/docs/resource-workflow)，交付问题见[故障恢复](/docs/troubleshooting#数据-脚本或拓扑没有运行)。
