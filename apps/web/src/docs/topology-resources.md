# 拓扑与项目资源治理

拓扑是应用内可复用的轻量关系图，不替代专业工艺设计软件。资源治理用于回答“资源来自哪里、被谁使用、当前实例改了什么”，不会复制模型和媒体文件。

## 创建并插入拓扑

1. 在项目工作台进入“拓扑”，点击“新建拓扑”。
2. 从左侧加入设备节点，选择“创建连线”后依次点击起点和终点。
3. 在属性面板配置名称、数据点位、阈值和连线语义。
4. 保存后刷新页面，确认节点和连线恢复。
5. 点击“插入看板”，拓扑会作为二维组件加入当前应用首页，可继续调整尺寸、层级和联动。

拓扑支持选择、多选、复制、对齐、自动布局、撤销重做、2D/2.5D 视图和运行状态诊断。实时值由数据适配器注入，拓扑文档只保存点位、阈值、关系和展示配置。

## 查看版本、依赖和实例覆盖

在项目工作台进入“资源库”，顶部“资源治理”按以下层级展示信息：

- 定义：项目中的模型、图片、视频或 Unity 资源。
- 版本：资源当前记录的版本数量；Unity 资源会检查实例引用的版本是否存在。
- 实例：二维页面或三维场景中的真实使用位置。
- 实例覆盖：可见性、透明度、变换、材质、动画、数据绑定等相对定义发生的修改。

资源行上的“已使用”或“未使用”标记来自当前项目的真实引用分析。删除已使用资源前会再次提示影响范围；未使用资源可以作为清理候选，但仍建议先确认它不属于待发布版本。

## 故障处理

- “引用版本不存在”：将实例切换到已有版本，或补回对应 Unity 构建版本。
- “资源未使用”：它当前没有页面或场景实例，不代表文件损坏。
- 删除后页面缺失：从应用历史版本恢复资源引用，再重新上传同一资源。
- 拓扑刷新后为空：先确认顶部已显示“所有修改已保存”，再检查当前项目和应用是否正确。

完成后按[发布检查](/docs/dashboard-scene#预览和发布检查)验证拓扑看板、三维场景和数据联动。
