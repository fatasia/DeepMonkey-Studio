# 常见问题

这里汇总安装、编辑与交付中容易混淆的问题。具体错误先按[故障恢复](/docs/troubleshooting)定位。

## 是否必须安装桌面客户端

Web 与 API 可独立运行。Windows 桌面客户端增加本地工作台与桌面集成；源码构建需要额外工具。先用[Web 快速开始](/docs/getting-started)验证需求，再选择运行方式。

## 是否可以完全离线

本地文档和已准备好的场景资源可以离线使用。桌面本地工作台支持本地编辑；外部 AI、远程数据、摄像头与在线发布仍需要对应服务。首次依赖安装和模型下载应在断网前完成。

## 保存后为什么发布页没有变化

保存更新草稿，发布更新运行版本。完成预览和体检后再次发布，再验证链接。若打开的是固定版本客户端，需要重新生成对应交付物；见[发布版本](/docs/core-concepts#草稿-预览与发布)。

## 换服务器后为什么看不到原项目

服务器地址决定访问哪一套项目数据，本地工作台也有独立的存储。切换连接不会自动搬迁内容。先回到原位置确认项目，按转移流程导出与导入，不要立即新建同名项目覆盖判断。

## 为什么模型能上传却不能显示

上传、格式识别、转换和可渲染是不同阶段。先查看处理诊断，再核对转换器、外部贴图、源版本和单位；具体步骤见[模型导入](/docs/model-import)。

## 为什么数据连接成功但图表没有值

连接测试不检查全部业务字段。继续运行数据集，检查字段、行数和空值，再执行流水线并检查组件绑定。尤其确认数字字段未被转换成带单位的字符串；单位应在展示层处理。

## 为什么视频能播放但没有识别结果

监控播放与视觉 AI 是独立任务。检查识别任务是否启用、模型是否就绪、采样是否运行，再看识别记录与诊断。停用识别模型不应被解释为视频源离线。

## WebGPU 和 Native 是否支持同一套能力

两者有独立的运行合同和验证范围。WebGPU 后端共享编辑器状态；Native 发布需要确认资源、二维组件、脚本与数据能力是否可交付。诊断中的缺失或降级项应在发布前处理，见[Deep Engine](/docs/deep-engine)。

## 文档不一致时以哪里为准

应用内文档跟随当前构建，仓库默认分支可能含下一版本的改动。报告时带上应用版本、提交号和文档标题；发行说明与对应版本源码用于复核行为。欢迎按[开发与贡献](/docs/contributing)直接修正文档。
