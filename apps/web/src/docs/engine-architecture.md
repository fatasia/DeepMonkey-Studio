# 引擎架构

Deep Engine 将场景描述、资源管理和渲染执行分层，供 Studio 编辑器与独立应用使用。

## 场景与资源

作者状态保存对象身份、属性和交互。运行时编译器将其转换为场景包，按修订和变化范围更新几何、材质、纹理与实例。多个渲染后端复用资源身份和相机状态。

## 执行后端

TypeScript WebGPU、Rust WASM 与 Rust 原生执行器按设备能力选择渲染路径。发布前检查目标后端支持的材质、灯光和效果；能力详情见[渲染能力矩阵](engine-capability-matrix)。

## 帧与生命周期

帧处理分为提取、准备、上传、可见性、编码和提交。资源按生命周期释放，实例与缓冲按变化增量更新。设备丢失、取消任务和退出走统一清理路径。

## 应用接口

DeepApp 提供插件、资源和帧阶段；Studio 脚本通过宿主 API 访问场景与数据。独立项目入口见[SDK](deep-engine-sdk)，性能排查见[渲染性能诊断](engine-performance)。
