# 管理资源并插入 2D / 3D

“资源”用于浏览和治理项目内容，真正的插入、摆放与参数编辑在二维或三维编辑器完成。公共资源保留原缩略图、材质和颜色；只有场景实例的外观修改会进入当前应用。

## 认识两个资源范围

在项目工作台打开“资源”，页面按范围区分内容：

- “公共资源”包含可浏览的二维资源、三维模型、环境和 PBR 材质。这里用于发现内容，不在卡片中重复编辑器配置。
- “项目资源”包含已上传或已引用的模型、图片、视频、环境和材质，并显示处理状态和使用位置。

先用搜索、类型和分类缩小结果。二维缩略图表达实际图形语义；三维资源可先预览，再到三维编辑器插入。

## 在二维编辑器插入资源

1. 打开场景后默认进入“二维”工作区。
2. 展开左侧“资源”，点击资源可按默认位置插入，也可拖到画布指定位置。
3. 单击实例，在右侧“属性”中配置内容、样式、数据和交互。
4. 点击画布空白处后，右侧才显示页面名称、分辨率、适配方式和背景等页面设置。
5. 对“三维场景”实例双击，或在右侧点击“进入三维编辑”，继续编辑同一应用的三维内容。

二维图层保持单行名称。`Ctrl` / `Command` 可多选，`Shift + 拖动` 可框选；选中多个实例后可编组、对齐、分布、锁定和显示隐藏。右键菜单提供复制、层级、编组、锁定、删除和进入三维编辑等就地操作。

## 在三维编辑器插入和整理资源

左侧“场景目录”包含“图层”和“资源”两个入口：

1. 在“资源”中搜索项目或公共资源；模型资源可直接加入场景，环境和材质会提示在属性检查器中应用。
2. 在“图层”中单击选择对象，按住 `Ctrl` / `Command` 多选后点击“编组”。
3. 拖动对象改变顺序，拖入组内完成归组，拖出组恢复到根层级。
4. 右键对象或编组可显示、隐藏、锁定、重命名、移出、解组或删除。
5. 左右面板都可从顶部收起；详细参数只在选中单个对象时显示。

选择模型后，在“外观”中使用“颜色调整”修改色相、饱和度、亮度和对比度，或点击“重置颜色调整”恢复资源原貌。PBR 材质、贴图和 UV 参数属于实例覆盖，不会改写公共资源。模型动画、火焰、轮廓和辉光等效果的设置见[三维效果、环境与物理光照出图](/docs/scene-effects-rendering)。

## 资产有新修订时

模型资源重新导入、转换或经参数化修改后会产生新的修订。场景里保存了它当时引用的修订号，如果项目资源里已经有更新的修订，对应的模型卡片会出现“已陈旧”标记，悬停可以看到“场景引用 r1，最新 r3”这样的对比。卡片上随之显示“资产修订陈旧”提示，说明受影响的实例数，并给出两个选择：

- “更新到最新版本”：把受影响场景里的引用改到最新修订并保存这些场景。过程中按钮显示“更新中…”，完成后提示更新了多少实例、影响了几个场景；失败时保留原因并出现“重试更新”。
- “保持当前”：本次会话内不再为这一修订提醒。刷新页面后提示会再次出现；如果之后又有更高的修订，也会重新提示。

更新之前先确认新修订的几何、单位和材质是否符合预期。已经发布的版本不受影响，需要让访客看到新内容时再重新发布。

## 删除前确认影响范围

删除模型、图片、视频、环境或材质前，系统会统计它在二维组件、三维场景和对象字段里的引用，项目资源卡片上的“已使用”标记也来自同一份真实引用。仍有引用时，确认框先写明“仍被 N 处引用，删除后引用会断开”，并在下面列出“影响范围”，精确到场景和字段路径，例如“某场景：models[0].assetModelId”，涉及场景较多时只列前几个。没有任何引用时才显示“确定删除未引用的……”。

这个确认只是提醒，不会替你修复断链。确认删除后，引用它的场景要手动换成其他资源，否则发布体检会报断链。模型仍在转换、转换失败，或者引用的版本不存在时，不要继续发布。

完成资源准备后继续[创建 2D / 3D 应用](/docs/dashboard-scene#编辑二维与三维)，数据来源见[连接数据、处理逻辑并发布接口](/docs/data-pipeline)。
