# 预览、体检与发布

预览用于验证当前草稿，发布会把当前内容冻结为独立运行版本。项目场景卡把“预览、编辑、发布、复制链接、重命名”作为常用操作直接展示，低频版本和导出操作放在“更多”菜单。

## 在项目页预览

点击场景缩略图或眼睛按钮直接预览，不必先进入编辑器。预览时重点确认：

- 首屏构图、二维比例、三维相机和文字可读性。
- 二维点击、筛选与页面跳转，三维对象选择、动画和脚本事件。
- 数据更新时间、空值、断流和重连提示。
- 图片、视频、实时监控、空间音频和 Unity 资源能否按预期加载。
- 不同窗口尺寸下没有遮挡、裁切或难以点击的控件。

发现问题时返回编辑器；二维、三维和脚本共用同一应用上下文，不需要复制场景。

## 交付前自检

在项目场景页展开“查看流程”，依次核对数据、资源、设计、联动、脚本、仿真、校验和发布。点击校验进入发布体检；阻断项会给出场景、目标和修复动作。

发布前至少完成：

1. 所有模型和媒体资源可用，没有断链或失效版本。
2. 数据集、流水线、字段和目标对象仍存在，并已成功预览。
3. 脚本已应用并运行，停止、重新运行和场景重载均无遗留错误。
4. Plant、PPR 或机器人任务使用的结果可复现，缺失证据已明确记录。
5. 预览完成关键操作路径，发布体检没有阻断项。

## 发布运行版本

在场景卡点击发布按钮：

1. 选择 WebGL 发布、WebGPU 优先或已配置的云渲染。
2. 选择“保持发布画质”，或在交付者明确允许时选择“允许极速模式”。
3. 决定发布浏览页是否显示适应全部、漫游、测量、剖切、爆炸和场景信息工具。
4. 点击“发布”，成功后从场景卡直接“复制链接”并打开验证。

WebGPU 优先模式在能力或画质不满足时会回退 WebGL 并显示原因。极速模式只在持续性能压力下减少阴影、后处理或刷新开销，不会改写模型几何与纹理。

## 生成单场景 Windows 客户端

Windows 单场景客户端从一个精确的已发布版本生成，适合在不填写服务器地址、无法稳定联网或只需现场浏览时交付。它会固化该场景实际引用的模型、贴图、环境和品牌资源，并可沿用发布时的 WebGL/WebGPU 优先策略和工具栏显隐设置。

这个客户端是只读浏览器，不是完整编辑客户端的改名包：只挂载专用场景浏览入口和只读接口，不提供项目管理、二维/三维编辑器、脚本编辑器、保存、发布、AI 或数据配置。作者行为脚本和实时数据不会在离线包中执行；需要这些能力时应交付 Web 运行版或完整客户端并连接服务。

打包会在 `.scene-viewer-build/<package-id>/web-dist` 生成专用 Web 产物，再复制到同一包的 `frontend` 目录。它不会复用、清空或覆盖普通 Web/编辑客户端的 `apps/web/dist`。构建清单必须包含 `SceneViewerRoot` 且不得包含编辑器入口，随后还会按发布快照移除未使用的导入器、物理运行时和公共资源目录。

当前生成和校验由发布运维命令完成，参数、精确版本选择与校验步骤见桌面端交付说明。校验会检查资源摘要、只读入口、能力集合和网络策略，但不能替代干净 Windows 中的真实安装、升级和卸载验收。

## 版本、撤回和再次发布

场景卡“更多”包含“查看发布版、版本历史、撤回发布、复制场景和导出”。版本历史会把已发布版本与当前草稿区分；恢复旧版本会生成新的发布记录，不抹掉原历史。

撤回发布只关闭公开运行入口，不删除当前草稿。修改后使用“重新发布”，原复制链接继续指向当前有效发布版本。

遇到断链、空画布、数据或脚本异常时按[故障恢复](/docs/troubleshooting)处理；完整起步流程见[从项目到首个可发布场景](/docs/dashboard-scene)。
