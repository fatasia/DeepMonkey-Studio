# 配置服务器并发布

本地客户端只保存一个当前服务器配置，但可以在服务器 IP 或端口变化后重新连接。账户、项目、场景和发布记录都由该服务器管理，客户端不复制账户体系。

## 连接服务器

1. 打开客户端连接页，填写服务器名称和 HTTPS 地址，例如 `https://studio.example.com:8443`。
2. 点击“检测连接”。客户端会读取服务实例标识和版本信息。
3. 首次连接确认实例；之后如果同一地址返回了不同实例，客户端会阻止自动发布并要求重新确认。
4. 使用平台账户登录。飞书、企业微信和其他身份提供方入口由服务器统一下发。

> 访问令牌只保存在当前运行时内存中。需要“记住登录”时，应由桌面安全凭据存储实现，不要把令牌写入普通配置文件。

## 无服务器 IP 的本地浏览

Windows 客户端首次启动可选择“本地工作台”，不填写服务器地址也能浏览、创建和保存本机项目，并可导出场景包或 GLB。本地模式不伪造在线发布、团队协作、工业 AI 或现场数据服务；需要这些能力时，再切换到服务器模式。

开发环境的 API 地址由仓库 `.env` 中的 `BIM_STUDIO_API_ORIGIN` 控制，未填写时使用 `http://127.0.0.1:${API_PORT}`。地址必须是完整的 HTTP(S) Origin；启动器会验证 `/api/meta` 健康状态。

## 切换服务器地址

修改地址前先保存当前应用。更新配置并重新检测后，客户端会清空旧会话，再要求登录新地址。由于部署只对应一套服务器，地址变化不会自动迁移项目数据。

桌面端写入配置时会先同步临时文件，再备份旧配置并激活新配置。若进程在替换阶段异常中断，下次启动会读取最近一次有效备份；配置损坏会显示明确错误，不会静默连接未知服务器。

## Windows 安装与升级

- MSI 与 NSIS 均为 64 位 per-machine 安装包，需要管理员权限。
- 升级前保存应用并退出客户端；同一产品升级码会识别旧版本并保留用户配置目录。
- 卸载只移除程序、快捷方式和安装登记，不删除服务器端项目数据。
- WebView2 缺失时安装器会引导安装运行时；离线部署应预先准备企业版 WebView2 运行时。

## 发布应用

1. 在编辑器执行保存，确保二维页面、三维场景、数据绑定和脚本属于同一个应用版本。
2. 点击“发布”，选择发布环境和入口页面。
3. 查看资源上传、应用校验和发布激活三个阶段的进度。
4. 发布成功后打开浏览地址，验证大屏分辨率、实时数据和三维交互。

## 发布失败处理

- “实例不匹配”：重新检测并确认当前服务器。
- “登录失效”：重新登录后继续发布，不要重复创建项目。
- “资源上传失败”：检查模型转换状态和对象存储连接。
- “应用校验失败”：根据错误定位失效链接、脚本或数据绑定。

第一次发布前建议先按[创建 2D 并绑定 3D](/docs/dashboard-scene#预览和发布检查)完成本地验收。
