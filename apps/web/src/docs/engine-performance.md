# 渲染性能诊断

在编辑器按 F9 打开“性能与诊断”，查看帧时间、场景、资源与管线。

## 定位瓶颈

- 首次打开慢：查看资源下载、模型解码、纹理上传和管线创建耗时。
- 连续操作卡顿：查看主线程长任务、帧时间峰值和重复上传。
- 大场景帧率低：检查可见对象、绘制调用、阴影和后处理成本。
- 内存持续增加：检查资源驻留、纹理大小和关闭场景后的释放情况。

## 调整设置

从平衡质量档开始，按设备能力调整阴影、反射、环境效果和分辨率。重复模型优先复用资源；大纹理按显示尺寸压缩。关闭不用的效果后再次记录同一段操作，核对帧时间和画面。

记录场景、设备、浏览器版本、质量档与操作步骤，分别测量首次加载、重复加载和持续交互。后端能力见[渲染能力矩阵](engine-capability-matrix)，架构见[引擎架构](engine-architecture)。
